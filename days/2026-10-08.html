模型 / 产品

GPT-6 Intelligent UI 怎么做的：原生可流式组件库（模型只挑组件、怎么拼）+ 界面编译器（边生成边渲染），训练时按清晰度、有用性、完整性给界面打分

M. @wlzh

GPT-6 开始全面推送了，覆盖"每周超过 12 亿"的 ChatGPT 用户。这次真正的看点不是模型变强了多少，是一个叫 Intelligent UI 的东西：回答不再只是一堆字，可以直接带出图形、按钮、表单、图表，甚至现成的交互工具。

逻辑很简单粗暴。问对比类问题，给你并排呈现；问原理类，给交互式图解；问简单的，还是纯文本。一句话：什么问题配什么形式。

技术上分两层，都在解决过去生成式 UI 的硬伤。第一层是原生可流式组件库，不让模型现场写代码，而是给它一套统一的组件，模型只管选哪些、怎么拼，跨 Web 和移动端体验一致，速度也快。第二层是界面编译器，模型边生成边渲染，不用等整个回复写完才出界面。之前这类产品的最大痛点就是延迟，这个算治本。

训练方法也跟着变：生成的界面按清晰度、有用性、完整性打分，模型自己学会什么时候该上交互、什么时候纯文本就够。OpenAI 自己都说"模型的设计判断仍需改进"，这话挺诚实的。

演示里几个场景还挺能打：烤肉计划直接带时间轴和食材用量表；自驾游路线落在地图上；中心极限定理、Monty Hall 问题都能交互着讲，改输入看结果变化；账单分摊、退休储蓄计算器、小游戏随口一说就造出来。

最扎心的是对比。同样问"周日烤羊腿"，GPT-5.6 给你一大段文字，GPT-6 直接甩出一个完整界面：人数调节器联动购物清单，烹饪时间线还能勾选。Adam.GPT 转发时那句"Dynamic, generative UI"，兴奋都快溢出来了。

agent 时代的瓶颈是人的理解：在自己专业之外做事时，先让模型把你不懂的教会你，再写 prompt 和计划

howie.serious @howie_serious

agent 范式下让人不适的真相：人的理解才是真正的瓶颈。（而不是 agent 和模型能力）

如推文所说，常见的失败模式是：人们在自己专业领域之外做事时，不知道怎么把 prompt 和计划写得精确，结果只能靠大量轮次"模糊地反复迭代"，既费时又费 token。

因为 agent 降低了门槛，几乎每个人迟早都会在自己专业之外操作，所以这是普遍问题，不只是非程序员的问题。

解法很简单：直接让模型先教你不懂的东西。

核心结论：ai 编程的瓶颈不在模型能力和 agent 能力，而在使用者能否精确表达需求。领域知识决定了表达的精度；缺知识时，先让模型补课、再动手，比盲目迭代高效得多。

一句话结论：agent 时代，甚至实现 agi 之后，人本身的理解会一直是瓶颈。

Landing Page 怎么写（再提）：首屏先写用户能得到什么，图片放原图和结果对比，评价必须真实，限时和名额真有才放

出海去孵化器 @chuhaiqu

首屏先写用户能得到什么，再说 AI、自动化这些技术。"突破英语听说障碍"就比先介绍功能好懂。

标题长短没有标准，判断方法很简单：让一个目标用户看完，他能不能用自己的话复述出来。

限时和剩余名额也一样，真有限制的时候才放。循环倒计时短期可能有点击，长期会伤信任。

古一 @MANISH1027512

VSC 开源专区最近又上新了一批创作工具，看看哪些能用进你的日常工作

1. ChatGPT 图片与提示词归档 作者： @VoxcatAI

把 ChatGPT 生成的图片、原始提示词和后续修改一起保存到 Eagle 或本地。以后找到一张好图，就能查到它是怎么生成、怎么改出来的，方便复用。

2.Eagle Plugin For GPT 作者：Richard Lee 在 GPT 对话里通过 @eagle 调用 Eagle 素材库里的图片。收藏过的人物、服装、构图，都可以拿出来作为生图参考。

3.图片大师 作者：汀树 自动保存 Comfly 生成的图片和提示词，方便集中查看、查找和下载。还支持粘贴抖店商品链接，批量提取主图、SKU 图和详情图。

4. 中国宝宝写真提示词大师 作者：汀树 提供宝宝照片、月龄和想拍的主题，就能得到完整的中文写真提示词。可以用来制作百天照、趣味主题照，以及同一个宝宝的系列写真。

5.Chromatic Fusion Portrait／色块共生视觉 作者：陆地神仙@李逍遥 根据人物照片，创作融合鲜明色块和机械拼贴的艺术肖像。可以用来做个性头像、人物海报，以及风格统一的系列作品。

6.潮流服装系统 作者：man！科比！ 根据人物设定，搭配服装款式、廓形、配饰和拍摄场景。可以给同一个角色设计多套穿搭，用来做虚拟人物造型、时尚写真和 Lookbook。

项目详情和使用说明都在 VSC 开源专区： https:// vibeshot.club/open-source，感谢各位作者分享！
