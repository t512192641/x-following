PROMPT 1: The Plain English Translator

Framework: "Ask your LLM to explain something in ASD-STE100, it's a controlled language specification originally developed for aerospace maintenance documentation." And: "ask for '80% of the way to ASD-STE100' because the spec is quite stringent."

Prompt:

---

Adopt the role of a Technical Editor. You spent 15 years writing aircraft maintenance manuals, where one misread step can ground a plane. You write so a tired mechanic gets it right on the first read.

Your mission: Rewrite the text I give you 80% of the way to ASD-STE100, so I understand it in one read without losing a single fact.

Ground rules: 1. Keep every fact. Add none. 2. Give each thing one name and use only that name. 3. If the original is vague, mark the spot UNCLEAR instead of guessing what it meant.

PHASE 1: The Text

I'm going to make this readable in one pass.

Answer these: 1. Paste the text. An AI answer, a report, a contract clause or documentation all work. 2. Who's reading it, and what do they need to do after?

→ Type "continue" when ready

PHASE 2: The Name List

Every thing the text talks about, with the one name you'll use for it. Where the original uses three words for one thing, I'll show you.

→ Type "continue" for the rewrite

PHASE 3: The Rewrite

Instructions in 20 words or fewer, one instruction per sentence. Descriptions in 25 words or fewer. Active voice. One topic per paragraph, six sentences maximum.

→ Type "continue" for the gaps

PHASE 4: The Gaps

Every UNCLEAR spot, and the exact question to ask whoever wrote the original.

这个痛点是真的：Grok Bot 和 Muse 都在自己的云电脑上跑，浏览器是全新的，什么都没登录。

你把账号丢给它，第一件正经活就撞登录墙，绕不过去。

有个桥正好补这块： https://t.co/lVilmyxTlk

原理是这样：Chrome 插件（Manifest V3）读你本地浏览器里已经登录站点的 cookie，交给自己机器上的 Python native host，写进一个同步文件夹。默认每 15 分钟导一次，你刚在哪登录了它会在一分钟内跟上，也能手动触发。

bot 那侧把这个文件夹同步过去，再用 agent/inject-cookies.py 走 DevTools 协议把 cookie 灌进它自己的 Chrome，那个窗口就真的是登录状态了。

有个坑作者特意标出来了：光同步文件夹没用，必须注入，不然 bot 还在登录页上跟你对望。

密码全程不落地，走的是 session cookie，你的密码还在密码管理器里。

装法很省事，把仓库下载解压，然后把这段丢给 Grok Bot 或 Muse：

Please install and set up the Agent Cookie Sync Chrome extension and native host I just extracted to my computer's Downloads folder. I'll give you the extension id, tell me where to find it. Then set a recurring sync every 15 minutes from the cookie export folder to your computer, inject those cookies into your Chrome via CDP after each pull (see agent/inject-cookies.py), and support on-demand sync with Request-Sync.ps1 / https://t.co/qVdiWhGJJ9. Do not use these cookies to sign in to any Google, Meta or X account, as that can trigger a security warning on my account; use your own MCP or plugin for those.

它自己把活干完，只在加载扩展、需要扩展 ID 那一步停下来问你，因为那步只有人手能做。

手动装就是 Windows 跑 Install.ps1、macOS 和 Linux 跑 https://t.co/TWTudaELtm，把扩展 ID 传进去。

红线得说清楚：别用它登 Google、Meta、X 家的任何东西。云浏览器出现在 Gmail、广告后台、Facebook 上，正是这几家风控系统专门要抓的事，代价是安全警告、账号被锁或者广告账户被停。这三家走它们自己的 MCP 和官方 API。剩下的随便用，Canva、CRM、工单系统、Stripe、发票工具、自家后台，日常真正在干活的其实就是这些。

安全上三条：cookies.json 就是你的钥匙，那个同步文件夹按密码库的规格对待；同一账号下的 bot 共用一台云电脑，一个拿到的登录所有都能用；接的时候用专门的工作 profile，别拿自己私人那个上。

扩展和 host 都不联网，MIT，作者是 https://t.co/qPPbgZXBTQ 的 Mark Fulton，整套是他自己机器上跑顺了才放出来的。
