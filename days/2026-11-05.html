4、这通常体现为：你可能会在内容的开头，用一个反常识的观点吸引住对方，而在对方看完整个内容之后，竟然发现你是对的

7、这里的核心是：刻板印象通常是简化的因果关系

这些规则的特点是：单一因果，忽略条件

【穹窿体是什么，为什么值得找】

穹窿体是一种空心的蛋白质“桶”，人体几乎每个细胞里都有，是已知最大的细胞内分子结构之一。1986 年 Leonard Rome 和 Nancy Kedersha 在电子显微镜下发现它，觉得它带肋条的外壳像教堂的拱顶，就起了这个名字。

科学家猜过它负责运输分子、帮细胞抵抗抗癌药这类毒物、参与免疫，都没被证实。天生缺穹窿体的小鼠也照样正常活着。

难研究的一个原因是，生物学家最常用的实验生物，酵母、果蝇、线虫，恰好都没有穹窿体。以前只在动物、植物这类复杂生物里见过完整的穹窿体。细菌里找到过相似的蛋白，但没人证明它们真能拼成桶。

这条路以前走通过：人类的好几种免疫机制，就是先在细菌里找到“远亲”，才弄清了来源。

第二步，把蛋白造出来。研究员挑了 44 个候选，Claude 把每个蛋白序列转成适合宿主细胞的 DNA 设计，加好控制开关，准备好下单。最后有 15 种在大肠杆菌里产出了可用的蛋白。

第三步，把颗粒分离出来。传统方法要约 3 天。团队想改用一种按颗粒大小筛分的柱子，Claude 一开始反对，理由是折叠坏掉的蛋白团块会和穹窿体一起流出来。

Anthropic 开源 FlashProve：给模型回答配一张“出生证明”

你现在调一个 API，回答到底是不是你点的那个模型跑出来的，其实没法从回答本身看出来。

Anthropic 11 月 2 日开源的 FlashProve，就是想把这件事变成可验证的。

思路不复杂，服务方先把模型权重做一个公开的“指纹”承诺，之后每次回答附上一份密码学证明。

验证方不用拿到权重，也不用把模型重跑一遍，就能核对这份回答是不是出自当初承诺的那套权重。

证明用的是 zkSNARK，好处是证明里不泄露权重本身。

Anthropic 拿 400B 的 Llama 4 Maverick 做了演示，4-bit 量化版本，在一块 H100 上每秒能生成 110 个 token 左右的证明。

一次 1024 个 token 的请求，证明大概 19MB，验证在 CPU 上就能做，十几秒量级。

代价也很实在，生成证明的 GPU 时间大概是正常推理的 70 到 95 倍。

所以这东西现在还不是能直接开在生产环境里的开关，更像一个研究原型。

Anthropic 自己也说了，这是阶段性进展，代码、Lean 形式化证明和文档都按 Apache 2.0 开源了，欢迎别人拿去改。

它真正有用的场景，我觉得是评测和审计：评测方想确认测的真是那个模型，客户想确认付费买的真是那个模型。

还有一个边界得说清楚，证明只能保证回答出自被承诺的那套权重，不能保证服务方当初承诺的名字就是真的。

换句话说，它防的是中途换模型，不防一开始就挂羊头卖狗肉。

但即便如此，能把“到底是谁回答的”从信任问题变成可验算的问题，已经往前走了一大步。

Fixed the mobile stretched interface on portrait mode in BF1942 by modding the engine

Claude Code told me how it did it:

"1. Spotting the HUD: 3D world draws use a perspective projection, where far things look smaller. The HUD uses a flat one. I can tell them apart from the projection matrix the game sets before each draw.

2. Measuring each element: before drawing a HUD piece (the ticket count, the map, an ammo icon), I calculate on the CPU where its corners land on screen. That uses the same matrix math the graphics card would do.

3. Squeezing it back: I shrink its height by that 2.9× factor toward a fixed edge depending on where it sits. Things at the top move toward the top edge, things at the bottom toward the bottom edge, and things in the middle toward the center. Because everything in the same band moves together, the map and its icons stay lined up.
