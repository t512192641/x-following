Claude + Sumi MCP = 直接起飞！

我一直说 Claude 是我的剪辑外挂。但有个误区要先讲清楚：Claude 能“做”视频，不等于能“生成”视频。

Claude 做视频走的是 Video as Code 路线。它用 Remotion、HyperFrames 这类框架，把画面写成时间轴上的代码，排版、动效、转场、调色、字幕，都能精确到帧。它最强的是编排：给它一段 BGM，它能分析出 BPM 和鼓点，精准卡点。 但它画不出一个真实的人，也做不出一束流动的光、一次转身扬起的发丝。这种像素级的真实画面，还是得交给视频生成模型。

所以我以前的流程一直是割裂的：图在一个平台生成，视频去另一个平台跑，配音再换一家，提示词另开窗口写，最后把一堆文件拖回来交给 Claude 剪。Claude 的品味和编排能力再强，也只能在你喂给它的素材里发挥。

这次接入 @sumistudio_ai 的 MCP，这个断点终于接上了。 Claude 可以直接在 Sumi 里调用模型、查看报价、生成素材、取回文件，然后接着剪。创意、生成、剪辑，在同一个对话里形成闭环。

这条韩蛛俐《白房间》就是这么做出来的： · Claude 先排好分镜和卡点，再按镜头决定用哪个模型生成 · 日语台词直接调 MiniMax 语音，玻璃碎裂、墨滴入眼这些音效也是现 · 去水印、超分、卡点特效、片尾卡，全部用代码完成

成本也比我预想的低： · 全片积分不到 1200 （参考，sd2.5 30秒720p消耗积分1500） · 我让 Claude 每次生成前先报价，我确认后才跑。简单镜头用 Wan3、H要质感的镜头才上 Seedance 2.5 · Claude 这边的 token 只用了周额度的 5%，而且是 20 刀的 Pro 账号 · 语音和音乐也能直接调 MiniMax 和 Suno v6，以前这些 API 都得我自

一句话：以前 Claude 是我的剪辑外挂，现在它是一整个制作组。

在终端里用 Claude Code 画架构图，它只把 mermaid 源码原样贴给你，图要复制到别的 app 里才看得见。merman 是个 Claude Code 插件，把回复里的 mermaid 代码块直接画成彩色字符图，图跟着回答一起出现在屏幕上。

它不注册工具，也不走 MCP，Claude 从不会调用它。做法是一组 TypeScript 钩子，接在回复和屏幕之间，重画 Claude Code 本来要显示的那段 markdown。流程图、时序图、状态机都能画，ER 图和饼图也在。插件只碰回复，Claude Code 自己的界面不动，停用它，自带渲染立刻回来。

装：

claude plugin marketplace add iamrohithrnair/merman && claude plugin install merman@merman

要 2.1.311 以上。装完 /reload-plugins，/merman setup 选主题。17 套配色，/merman theme nord 当场换，/merman demo 看它能画什么。

图是字符画的，有边界。宽度超出窗口、或超过 80 行的图它不画，仍旧显示源码，大的时序图还是会退回别处看。C4 图目前不支持。

模型的账只有一笔：一条约 355 token 的说明，告诉它这个会话里可以放心画图，只加在第一条提示里，压缩掉之后补一次。把 diagramHints 关掉就一个 token 也不发。渲染这边，一条带六张图的完整回复首画中位 1.8 ms，重画 0.29 ms。插件 616 KB，没有网络请求，MIT。

我的判断：它的价值在迭代成本。改一支箭得把源码复制出去，切到别的 app 看一眼再回来重说一遍，一轮几分钟；它把这个循环压进同一条回复。图最终要拿给别人，还是得点 ▣ png 导出成图片。
