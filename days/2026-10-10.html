REA：让 AI 智能体帮你逆向没有源码的软件

开源项目 REA（Reverse Engineer Anything）把逆向分析工具接到了 Claude Code、Codex、Cursor 这类 AI 编程智能体上。看到别人 App 里有个好功能，可以让智能体去拆这个程序，讲清楚功能是怎么实现的，附上证据，再在你自己的项目里写一个类似的。逆向分析指的是手里没有源代码，从编译好的程序反推它是怎么写的。

REA 本身是一个 MCP 服务。MCP 是 AI 智能体调用外部工具的通用接口，接上以后，智能体在对话里就能直接调用 REA 的分析功能。安装只需一行命令 npx rea-agents setup，它会注册到 Claude Code、Codex、Cursor、Gemini CLI、Grok Build 等智能体里，改配置前会先备份并让你确认。不用智能体的话，也可以在终端里直接跑命令。

能分析的东西很多。原生程序（直接编译成机器码的软件）要借助 Hopper、Ghidra 或 IDA 这几款反汇编工具，把机器码还原成汇编和近似 C 语言的伪代码。Electron 应用（用网页技术做的桌面软件，比如 Notion）可以直接拆开安装包里的 ASAR 归档文件，理清模块和进程间通信，不需要额外工具。此外还支持 .NET 程序、安卓 APK、固件、网站、抓包记录、以太坊合约字节码，以及在 Linux 和 macOS 上记录程序运行时的行为。

分析在本机进行，REA 不上传目标程序，但分析结果会交给智能体背后的模型服务商，数据怎么处理看各家政策。

项目给了三个案例。一是经典打砖块游戏 DX-Ball：从一次播放音效的调用，追到根据球的位置计算左右声道的函数，把不完整的伪代码还原成 C 代码，3205 组测试结果和原版一致，编译出的 63 个字节也和原版完全相同。二是 Notion 桌面版：追踪复制粘贴从界面一路经过预加载脚本、进程间通信到主进程的完整链路。三是日本老电脑 PC-98 上的游戏《东方幻想乡》（TH04）：从 16 位指令里还原出弹幕子弹环的角度算法。

对安全研究员、做老游戏复刻和软件保存的人来说，以前要自己对着反汇编工具一行行读、一层层追调用，现在可以让智能体先追，人来核对它给出的证据。普通开发者想研究竞品某个功能的做法，也多了一条路。

README 显示项目在 GitHub 上已有 5 万星。npm 包今年 7 月首次发布，最新的 6.3.0 版今天刚发。

使用前注意两点。项目声明只支持合法的逆向研究，授权和合规由使用者自己负责，逆向别人的软件可能违反用户协议或版权法规。项目还说明从未发行或背书任何加密货币，借用 REA 名字的代币都与它无关。

公开我最近的项目：strata-mlx

Strata 非常棒：它能在一块 12 GB 的显卡上跑 125B 参数的混合专家模型 Qwen3.8-Flash-Next。但它的作者说过，macOS 不在支持范围内。

我还是想让它跑在 Mac 上。

所以我花了一天半，写了 strata-mlx。它是一个非官方的 MLX 引擎，借鉴 strata 的设计，直接读 Strata 的 GGUF 文件，不用修改权重。

我在一台 128 GB 内存的 M4 Max MacBook Pro 上开发，经过一次又一次的实验，终于得到了一些成果。下面的单位都是 token/秒，越高越好；Q2_0 和 IQ3_S 是模型的两个文件，66 GB 和 84 GB。

写回答（左 Q2_0，右 IQ3_S）：strata-mlx 是 llama.cpp 的 1.7–2.9 倍，LM Studio 的 1.6–2.6 倍 strata-mlx：Q2_0 68–111，IQ3_S 65–95 strata-mlx，不用草稿头：44–67，43–56 llama.cpp llama-server 0.4.1：38–39，35–36 LM Studio 0.4.25：43，40

读一段 1,180 token 的提示：strata-mlx 是 llama.cpp 的 1.04–1.17 倍，LM Studio 的 1.20–1.36 倍 strata-mlx：570–578，510–517 strata-mlx，不用草稿头：595–612，504–515 llama.cpp llama-server 0.4.1：494–495，488–489 LM Studio 0.4.25：426–446，421–424

草稿头是模型自带的一个模块，先猜后面几个 token，再由模型一次验证；它只作用于生成，读提示时不用它反而略快，另外两个引擎没有用它。

我做这件事的初衷是：不是每台 Mac 都有 128 GB 内存。在一台装不下整个模型的 Mac 上，strata-mlx 会把能放下的专家留在内存里，剩下的按 token 的需要从 SSD 读。按引擎自己的估算，48 GB 的 Mac 能整份装下 Q2_0 文件，完全不碰磁盘；内存再小，就要边跑边从 SSD 读。

我把自己的 Mac 限成小内存机器来测：66 GB 的文件跑在 16 GB 机器的内存里是 6–7 token/秒，24 GB 是 19–23，32 GB 是 28–47。这个模式下读一段 1,537 token 的提示是 273–287 token/秒。

所以小内存 Mac 能跑一个远大于自己内存的模型，但执行速度方面无法保证。

我希望有人可以参与这个项目，测试不同内存大小的 Mac 设备用它跑 LLM 的效果。这样我可以持续改进。

VPS 只有 IP 没有域名，怎么免费上 HTTPS？给你说全了。

先说个冷知识：Let's Encrypt 不给纯 IP 颁证书，它只认域名。所以得绕一下，三条路：

1. 最省事：ZeroSSL。免费版可以直接给公网 IP 颁证书（90 天有效，一个账号能拿 3 张）。去 https://zerossl.com/ 注册，填你的 IP，选 HTTP 文件验证——把验证文件传到服务器网站根目录，验证通过就下载证书，配到 Nginx 上完事。注意只支持 IPv4。

2. 最推荐：https://nip.io/ 白嫖"域名"。比如你的 IP 是 1.2.3.4，那 https://1.2.3.4.nip.io/ 这个域名天然就解析到你的服务器，不用注册不用花钱。然后用 https://acme.sh/ 或 certbot 走 HTTP 验证申请 Let's Encrypt 证书，还能自动续期。零成本拿下域名加证书。

3. 最正规：搞个免费域名（DuckDNS、https://eu.org/ 这些），A 记录指到你的 IP，然后正常走 Let's Encrypt，一劳永逸。

自签证书就别考虑了，浏览器直接报红"不安全"，访客扭头就走。

小白闭眼选方案 2，十分钟搞定，之后全自动续期不用管。
