程序员小灰 @XiaohuiAI666

再给大家推荐两个最新的好用技能：

1. Self-Improving / 自我进化技能（self-improvement 或 self-improving-agent）

解决的问题：AI 用久了还是会反复踩同样的坑、记不住你的偏好和纠正，每次都像重新认识你。

这个技能会把你的明确纠正、偏好、成功经验和失败教训沉淀下来（性格/身份/用户偏好/工作流/技术记忆等分层存储），跨对话甚至跨项目复用。用得越久，WorkBuddy 越贴近你的真实习惯，同类问题越来越稳、越少返工。

官方有专门说明，社区也有多个实现（包括跨项目版本）。它是“元技能”，装完文章里那些创作/设计/开发技能后，能让整体体验持续提升，而不是一次性工具。

安装方式： 直接对 WorkBuddy 说“帮我安装 self-improvement 技能”或“搜索并安装自我进化技能”，也可以在技能市场搜相关关键词。

GitHub 上可参考类似 Benson-xie/workbuddy-self-improving-agent 这类实现。

2. Content Repurposer / 内容再加工技能（content-repurposer）

解决的问题：写完一篇好文章（用 Humanizer-zh + 写作蒸馏器打磨后），还要手动改成小红书图文、推文、短视频脚本、LinkedIn 帖等多平台版本，又费时间又容易风格不统一。

它采用 Hub & Spoke 思路：先提取长文的核心论点、关键要点、故事和数据，再按目标平台重新适配成一套短内容包（社交帖、要点卡片、视频脚本等），而不是简单摘要。和文章里的写作链、归藏社交媒体卡片正好串起来，形成“写 → 去痕/定风格 → 视觉化 → 多平台分发”的完整闭环。

开源实现不少，例如 superamped/ai-marketing-skills 里的 content-repurposer，或专门做博客转社交帖的仓库。

安装方式： 对 WorkBuddy 说“帮我安装 content-repurposer 技能”或“找一个把长文转多平台内容的技能”，也可以直接给 GitHub 链接让它安装。安装前建议先扫一眼 SKILL.md，确认来源和权限。⁠

大家还有哪些常用的技能？欢迎在留言区说一说。
