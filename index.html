真正的变化在动作选择。这个 4B 策略里没有外部路由器，模型自己判断这一步走哪个通道：视觉布局、画布编辑、应用里的实时状态，走 computer_use，11 个 GUI 原语加归一化坐标；表格、文档这类结构化编辑，以及做完后的确定性校验，走 bash，一个持久 shell 加 Python 环境。背后的直觉很简单：在菜单里点几十下改一个 xlsx，不如直接用 openpyxl 写文件；但改一张图的视觉效果，脚本写不了。

训练配方有三步值得抄作业的人看。

1. 先修教师 harness 再收轨迹。微软发现强模型拿到冗余工具也会养成坏习惯，而且坏习惯会蒸馏给学生。删掉 xdotool 和冗长的无障碍树这类重复通道、预装领域 Python 库后，GPT-5.4 教师升到 92.0%、步骤少 29.2%，学生对应 +12.5 个百分点（37.6% 对 25.1%）。

2. 题库按技能复用。Mage-CUA-Forge 为每一项原子技能写一次生成工作流，而不是每个任务跑一遍开放式 agent 循环。共产出 293,806 个任务、覆盖 6,915 项技能，单任务生成成本从 0.906 美元降到 0.158 美元，降了 82.6%。

3. 五阶段先分练再合并。视觉 grounding、GUI 执行、终端能力分别训练，再用 Hybrid SFT 学通道切换，最后在线 GRPO 用可验证的任务结果做强化学习：45.56% 到 55.84% 再到 66.0%。在线 RL 这一步加了 10.16 个百分点，同时平均模型调用从 21.57 次压到 18.77 次，输出 token 从 7,374 降到 5,499。

但如果你还处于探索阶段，过早收敛反而可能限制思路。

所以，在和 AI 交流的初期，最好就给出明确的指示。同时，自己也要清楚，现在究竟处于 Double Diamond 的哪个阶段？是在发散，还是在收敛？
