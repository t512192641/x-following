Browserr 开源：基于 Servo 的 Agent 无头浏览器，协议只有 22 条命令，自带 42 个 MCP 工具，约 120MB 零依赖

M. @wlzh

M. 介绍刚开源 4 天的 Browserr：跑在 Servo 上的无头浏览器引擎，专门给 AI 智能体用，不再套 Chromium。它不走 CDP 那套上千个接口，整个协议只有 22 条命令，JSON 走本地回环，称一个下午能审计完。MCP 是原生的，直接提供 42 个工具，Claude、Codex 等能接 MCP 的客户端不用写集成代码就能用。一个二进制大约 120MB，零依赖，默认 CPU 渲染，没显卡的机器、容器和树莓派都能跑。设计上是 fail-closed：不确定的请求先拦下来，5 秒没人拍板就拒绝，付钱和验证码必须人来确认；验证码、一次性码和付款页能自动识别，pause 后把页面交还给真人，截图上每个元素都编了号。每次操作留下带时间戳的截图和只追加的操作日志。React 18 和 Vue 3 都能跑，Windows、Linux、macOS 都有包，Python 3.10 以上可用。仓库在 Omodaka9375/browserr，Apache-2.0 协议。

小小东在研究字体提示词，觉得 ChatGPT 对这块理解有限，偶尔调出好用的会比较激动。这组简约风的核心是：围绕任意主题名称或短语，把语义转成居中、安静、可识别的线描字标；大面积高明度洁净底，接近白色但保留纸面或数字哑光的温润，不加纹理噪点或装饰场景。核心文字用极细到中细的单线笔画，重心稳定、端点圆润、竖线修长、横线短而克制，局部用断笔、留口、错位衔接和共享笔画制造识别张力；主题中的字词可被简化、拉长或拆分，但必须保持可读性和呼吸感。主字标放在视觉中心附近并大量留白，下方一行更小的同源辅助文字，底部再放一个极小、低透明度的几何徽记。色彩随主题派生：底色占绝大部分，主文字用低饱和深色承担识别。完整提示词见原帖。
