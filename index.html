Noah Shinn 谈 Instinct：一个每天涨 10% 的 personal agent

Instinct 创始人 Noah Shinn 上了 Invest Like The Best，跟主持人 Patrick O'Shaughnessy 聊了一个多小时。他之前是 Sierra 的早期员工，Instinct 去年才创办，8 月开始邀请制测试，没做营销，靠口碑传开。主持人在节目里提到，Instinct 最新一轮融了约十亿美元，估值约百亿。

Instinct 是一个 personal agent。它没有 App，你给它发短信、打电话就行，它用自己的手机和电脑去帮你订位、买东西、退订阅、约时间。Noah 讲得最细的是信任，用户要用上几周才敢把信用卡交出去，他说第三周大约四成用户会交，交过敏感信息的人大多留了下来。商业模式上他不想靠广告劝用户买不想要的东西，打算按交易抽成。他自己最发愁的是算力，用户每天涨 10% 左右，算力却要提前几个月买。

拿最近几个 personal agent 比一下会更清楚。Grok Bot 8 月 11 日开放测试，几个 bot 共用一台云端电脑，更像给你配了一组同事，主要冲着工作去。OpenClaw 和 Hermes Agent 都是 MIT 许可的开源项目，OpenClaw 要你在自己的电脑或服务器上跑一个网关，再从 WhatsApp、Telegram、iMessage 这些聊天软件里找它。Hermes Agent 是 Nous Research 做的，会记住你的项目，还会把做过的事自己攒成 skill。Instinct 走的是另一头，什么都不用装，拿到邀请就能直接发短信用，目前对受邀用户免费。

Muse 是 Meta 的 personal agent，9 月 8 日在美国上线，18 岁以上就能用。它有单独的 Muse App 和 https://muse.ai/ 网页，也能直接在 WhatsApp 里给它发消息，只是 WhatsApp 里没有 App 上的信息流。登录用 Meta 账号。接上邮箱、日历这些 Connector 以后，它能发邮件、订行程、设提醒、做文件，付款和购物前会先问你。免费版有用量上限，用得多要订每月 20 或 100 美元的套餐。跟 Instinct 比，Muse 有自己的 App，在美国注册就能用，Instinct 没有 App，目前还得拿到邀请才能进。原视频标题里点名的另一家是 OpenAI 的 Dots，The Verge 把它跟 Muse 归为同一类产品，在 Muse 之后不久推出。

Alex Prompter @alex_prompter

You shouldn’t trust an AI model to follow the rules just because you put them in a prompt.

If a rule matters, enforce it in code the agent can’t change.

That’s how we’re building Velocity Core, which runs agents inside our software factory. A run has 22 steps. Only three are left entirely to the agent. Fourteen are plain code.

Here’s what that means in practice:

1. Credentials stay outside the agent. Code fetches the repository before the agent starts and pushes the result after it finishes.

2. It can’t change its own rules. Each run reads them from its starting commit. Changing those rules requires a person’s approval.

3. Outbound access is restricted. Requests must pass an allowlist. Secret scanning checks the code changes, logs and pull request text.

4. “Done” isn’t proof. CI determines whether the work passes. The agent gets a maximum of two CI runs.

5. Deleting tests doesn’t get it a pass. If it deletes or empties a test, the work goes back for correction. A second violation ends the run.

6. Every run leaves a record. Prompt versions, the exact model used at each step, the starting commit and the cost.

A person still reviews and merges every pull request.

Building the agent loop is easy. The hard work is building a platform that enforces these boundaries on every run.

That’s where we’re building our advantage.

你不应仅因为将规则放入提示中，就相信一个AI模型会遵守这些规则。

如果一条规则很重要，就在代码中强制执行它，让代理无法更改。

这就是我们构建Velocity Core的方式，它在我们的软件工厂中运行代理。一次运行包含22个步骤。只有三个步骤完全交给代理。十四步是纯代码。

以下是这在实践中的含义：

1. 凭据始终在代理外部。代码在代理启动前获取仓库，并在完成后推送结果。

2. 它无法更改自己的规则。每次运行都从起始提交中读取这些规则。更改这些规则需要人工批准。

3. 外部访问受到限制。请求必须通过允许列表。秘密扫描会检查代码更改、日志和拉取请求文本。

4. “完成”不是证明。CI决定工作是否通过。代理最多获得两次CI运行。

5. 删除测试不会让它通过。如果它删除或清空测试，工作将返回进行修正。第二次违规将结束运行。

6. 每次运行都会留下记录。提示版本、每个步骤使用的确切模型、起始提交和成本。

人类仍然会审查并合并每个拉取请求。

构建代理循环很容易。难点在于构建一个平台，在每次运行中强制执行这些边界。

这就是我们建立优势的地方。
