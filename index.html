M. @wlzh

开源 Mirobody skill：把体检单、手环和基因文件做成带出处的标准记录，可本地部署

Asa @app_sail

有人写了怎么用 Codex 等 agent 加上开源 Mirobody skill，帮家人看体检报告。Mirobody 能把体检报告、手环数据和基因文件整合成同一份标准记录，回答里的每个数字都标明来源、能点开原文件。Apache-2.0 开源，截至 2026 年 11 月 18 日 GitHub 有 1,554 星。安装是让 agent 从公开仓库把 skills/standardize-health-data 装成本地 Skill，或执行 npx skills add thetahealth/mirobody --skill standardize-health-data，再用虚拟指标跑一次 mirobody resolve 做离线自检；Windows 若中文乱码先设 PYTHONUTF8=1。装好后把中英文体检单、化验指标或手环导出喂给 agent，先把名字和单位统一成标准编码再分析。遇到「血脂」这种笼统大类词会返回 unresolved，拒绝瞎猜；公开文档里中英日等 6 种语言的 347 项常规体检识别测试全对。若要给家人长期代管健康档案，可让 agent 按仓库里的 skills/mirobody，用 COMPOSE_PROFILES=local-cpu ./deploy.sh 在本机 100% 本地部署，16GB 内存没显卡也能跑，第一次纯 CPU 回答要等几分钟。完整版在设置里生成的 MCP 接入链接相当于密码，截图前必须打码。把体检单喂给云端 agent 时，记录会发给对应模型公司；介意就走本地部署。结果仅供参考，不做诊断。也有中文 demo 可先看预设问答。

用 AI 做不丑且易用的产品：11 条可交给 Agent 审查仓库的清单

Tw93 @HiTw93

Tw93 从产品工程师视角写了怎么用 AI 做出不那么 AI Slop、既易用又不丑的产品，并说可以把这一大段交给 Agent 去审查代码仓库。优先级是能解决问题，其次易于使用，最后才是好看。清单包括：把自己当小白走完主链路，卡点和没讲明白的地方全部修好；文案要符合当地使用习惯，能用界面说清就不要再加说明；数字要带单位并校验准确；只有不可逆操作才二次确认，危险操作不要大片红；一个页面只留一个强调色，少用橙、陶土和老式亮蓝，灰色用偏暖的；一个页面最多 4 种字号，保证对比度和节奏；少用斜体、等宽和全大写，同一动作只用一个动词；按钮、间距、圆角、阴影规范一致，页面默认是平的，阴影只给真正浮起的弹窗，嵌套圆角要同心；多语言先按最长文案排，不要为了好看改字号或截断；反复调不好的设计，让 Agent 出 3 个方案再挑一个打磨，他喜欢把前后对比图放进一份 PDF。最后强调要有耐心，常为文案、颜色和设计跟 AI 讨论十几轮。
