提示词 / 方法

把 ChatCut 接到 Grok Bot：口播 5 分 46 秒剪到 3 分 40 秒，大文件先走上传页；验收要看片头黑闪和片尾文字

泊舟 @bozhou_ai

泊舟试用后认为，Grok Bot 自己写代码做视频画面糙、改一版就要整段重跑，token 也烧得快；ChatCut 现已官方支持直接接进 Grok Bot。他试了两条：一条 5 分 46 秒口播，只要求剪掉口误、精简，并配上对应动画和特效，回来是 3 分 40 秒成片，字幕和特效也一起配好了；另一条从博客扒出文字稿再做成约 1 分钟教学视频。ChatCut 里加字幕、MG 动画、调色是免费的；克隆音色、AI 配乐、生成视频和图片属于 Pro。安装三步：在 Grok 里新建或打开一个 Bot，发给它「Read https://chatcut.io/grok to connect the ChatCut app」，它会读安装指南并弹出连接卡片，授权登录后技能会保存，他这边还直接读到了账号里原有的 14 个项目。有一个坑：视频不要直接丢进聊天框。他那条口播有 700 多兆，Bot 说聊天里传容易失败，会另建一个 ChatCut 上传页；正确顺序是先说需求，等它给上传链接，传完再回一句「上传好了」。ChatCut 是云端环境，手机和电脑可以在同一项目里迭代，也可以跨多个 Agent。

Alpha 补了一句最值得抄的第 4 步验收：初版片头短暂黑闪、片尾文字不够清晰，都是预览时挑出来再让 Bot 改的；史料准确性和素材版权得自己把关，Bot 搜来的资料先按整理好的来源核一遍再进剪辑。

做好 Agent Skills 可先和 Agent 跑完一遍 SOP，再让它按这段提示词把步骤、判断和容错封装起来

铁柱AGI @cgnot996

铁柱AGI 推荐参考 Matt Pocock 沉淀 Skills 的方法：先把事情做成，再把成功经验封装起来。不要坐在那里凭空写 Skill，而是先和 Agent 完整执行一次 SOP，过程里的问题、坑和有效办法都有现成上下文；等任务顺利完成，再让 Agent 回顾全过程，提炼可复用步骤、判断条件和异常处理。他配了一段可直接复制的提示词：

我们刚刚一起完成的这个任务，以后应该还会重复做。你先回顾一下整个过程，结合我发给你的这篇文章，看看怎样把它整理成一个方便以后直接调用的 Skill。重点保留真正有效的操作步骤、关键判断、容易出错的地方，以及出错后怎么处理。过程中的临时尝试、无效操作和这次任务独有的信息就不要放进去了。请把适用场景、需要我提供什么、执行步骤和完成后的检查方式写清楚。能自动完成的尽量自动化，需要我确认的地方保留确认步骤。按照当前 Agent 支持的 Skills 规范生成文件，能用已有工具和脚本的就直接复用，不要为了做 Skill 增加不必要的复杂度。完成后用刚才的任务做一次验证，看看有没有遗漏、错误或者不合理的地方。先把整理好的 Skill 和验证结果给我看看。

企业 AI 落地可先做培训和系统接口化，再上元 Agent 和数据报表；生产链路优化不要一上来就做

Yangyi @yangyi

Yangyi 把企业 AI 落地拆成先处理存量、再做增量的顺序。前三步就能覆盖大部分初级场景：1. 用企业培训切入，建立信任；2. 用 OpenCLI 等方式自动逆向内部各类 SaaS，把核心操作接口化，给 Agent 当工具；3. 做元 Agent，按不同场景自动构建 Agent 去跑流程。有了接口和 Agent 之后再深入：4. 把企业数据连成报表看板和预警，看成本项和 SKU 定价；5. 逆向微信客户端，打通微信上的企业数据，自动报告需求并辅助老板决策；6. 客户画像分层和生命周期管理，用邮件、企微、外呼等 SCRM 做激活转化；7. 把聊天和电话记录数字化，做质检和优秀话术沉淀；8. 用这些数据优化销售培训，构建 Benchmark 做培训和汰换。再往后才是 AI 营销获客，最后才是因企业而异的生产链路优化。他提醒：生产链路优化是在有限天花板里省钱，最慢、最得罪人、也最难落地；很多不懂 AI 的企业一上来就想靠这个砍掉几个人，而很多做培训或 FDE 的也爱先冲生产环节，属于本末倒置。
