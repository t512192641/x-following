AgentCore Web Search：域名黑白名单 + 发布日期过滤

yibie @yibie

yibie 全文转写 AWS（2026-08-19）《Domain and publish date filters for Web Search on AgentCore》。AgentCore Web Search 随 connector 1.2.0 支持按次 tools/call 传 filters：domainFilter.include/exclude（各最多 100 域名）与 publishedDateFilter.from/to（ISO-8601 UTC，含边界）。规则在服务端强制，agent 改不了；省略则行为与旧版相同。

分层模型：运行时只能收窄、不能扩大管理员范围。include 取交集（运行时多出的域名静默丢弃）；exclude 取并集。Gateway 合并管理员策略与运行时过滤后再查索引；无法验证域名或发布日期的结果排除（偏精确率）。

场景：合规 agent 只搜 .gov；市场情报限「本周」；多租户按请求换黑白名单；客服只取近 7 天文档。区域新开 eu-west-1 / ap-northeast-1；零外流，查询留在 AWS。

文内含 Boto3 建 target、tools/call 示例，以及临床研究助手、股票更新、投资者关系合规、多租户 SaaS 等用法。04-articles 已 overlay（~11.6k）。原文 https://aws.amazon.com/blogs/machine-learning/domain-and-publish-date-filters-for-web-search-on-agentcore/

小互 @xiaohu
