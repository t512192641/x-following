Qwen3.8 27B 本地部署：Mac / N 卡选型 + 4090 实测

huangserva @servasyy_ai

huangserva X 文章《一次性讲清楚 Qwen3.8 27B 的本地部署》（从零开始 · Mac 与 N 卡两条路线 · 附 4090 实测）。Apache 2.0；27B 稠密、原生多模态、定位端侧 Agent；256K 上下文可扩 1M；混合注意力（64 层仅 16 层全注意力）使 KV Cache 约省 75%；MTP 官方内置于模型文件。

选型（作者推荐）：默认 Q4_K_M（16.5GB，装得下就用）；12–16GB 卡短任务用 Q2_K_XL（9.83GB）；IQ2_S/IQ1_M 别用。社区 agent 长任务：Q2 27/41 vs Q4 35/41，16GB 想跑长任务可优先试 Q3_K_XL。原版 BF16 55.56GB 消费卡装不下。

关键结论：窗口开大主要占显存、不直接拖慢短对话；内容塞满才会明显变慢（256K 空载 78.80 tok/s vs 满载 250K 47.70，显存几乎一样）。量化代价常是「答对了但想得更久」。KV 压到 q4：256K 省约 4GB，速度约掉 4%。MTP3 生成约翻倍、多占约 2.9GB。

分档体感（作者 4090 实测线）：12GB 可跑短任务；24GB 推荐 Q4+q4 KV+MTP3 开到 192K（约 22.6GB / 59.52 tok/s），别硬开 256K（余量仅约 154MiB）；32GB+ 可开满 256K。装机约 14 分钟（下载为大头），国内走 hf-mirror；llama.cpp build b10441。Mac 16GB 条件苛刻可到 4–6 tok/s（关思考/小窗口/防 swap）；24GB 起步更靠谱。

可接 Claude Code：ANTHROPIC_BASE_URL=http://127.0.0.1:8080。完整命令与坑见原文章（约 2 万字）；另有实测长文《想证明量化版更差，我测了四轮都没证成》。04-articles 已 overlay，数字摘自原文，未发明。

AgentCore Web Search：域名黑白名单 + 发布日期过滤

yibie @yibie

yibie 全文转写 AWS（2026-08-19）《Domain and publish date filters for Web Search on AgentCore》。AgentCore Web Search 随 connector 1.2.0 支持按次 tools/call 传 filters：domainFilter.include/exclude（各最多 100 域名）与 publishedDateFilter.from/to（ISO-8601 UTC，含边界）。规则在服务端强制，agent 改不了；省略则行为与旧版相同。

分层模型：运行时只能收窄、不能扩大管理员范围。include 取交集（运行时多出的域名静默丢弃）；exclude 取并集。Gateway 合并管理员策略与运行时过滤后再查索引；无法验证域名或发布日期的结果排除（偏精确率）。

场景：合规 agent 只搜 .gov；市场情报限「本周」；多租户按请求换黑白名单；客服只取近 7 天文档。区域新开 eu-west-1 / ap-northeast-1；零外流，查询留在 AWS。

文内含 Boto3 建 target、tools/call 示例，以及临床研究助手、股票更新、投资者关系合规、多租户 SaaS 等用法。04-articles 已 overlay（~11.6k）。原文 https://aws.amazon.com/blogs/machine-learning/domain-and-publish-date-filters-for-web-search-on-agentcore/

17 岁苏庭灏 ICML 主会：ExoFormer 外生锚点抗过度平滑

姚金刚 @yaojingang

姚金刚荐张小珺访谈：香港国际学校高中生苏庭灏，独立完成论文《Attention Projection Mixing with Exogenous Anchors》，经双盲评审进 ICML 主会。

问题：Transformer 深层过度平滑，词身份被冲淡。已有方法反复回看第一层，但第一层既要产出可长期复用的稳定信息、又要做自身语义计算——First-Layer Tension。

ExoFormer：在正常层外设「外生锚点」——从输入词向量提取稳定表示；生成 Q/K/V 与门控 G；每层可与锚点混合（比例可学/可随输入变）；注入前 RMSNorm。锚点保身份，主网做高级特征（卸载假说）。

六项下游平均准确率：门控注意力 48.80% → 50.27%；验证集困惑度从 14.x 改善（详见论文）。播客 https://xiaoyuzhoufm.com/episode/6a8472b95aeb2a5712e8de78 ；论文 https://arxiv.org/html/2601.08131v4
