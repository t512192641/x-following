今天分享的开源项目是 OpenSEO

https://openfree.tools/zh/openseo

OpenSEO 是 Semrush / Ahrefs 的开源替代，支持关键词研究、排名追踪、竞品分析、反向链接和网站审计。还提供 MCP 和 Agent Skills，让 AI 助手直接参与 SEO 工作流。支持自托管，数据 API 按量付费。

OpenSEO 是 DataForSEO 的产品，所以其实它是开源，但非免费。最近发布了价格，最低每个月$10，真心划算。不过我也试了下自托管，它是可以直接部署到 Cloudflare 的，图片就是效果，真的很推荐。
