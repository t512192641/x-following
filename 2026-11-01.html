核心数字：OSWorld-Verified 66.0%，361 道留出题、50 步预算，两次完整跑分平均。对比同表，Qwen3.6-27B 是 63.9%，Muse Glimmer-30B 是 65.9%。不过 ScaleCUA-Qwen3.5-9B 是 68.7%，比它高，所以这不是「小模型全面赢」的故事。

真正的变化在动作选择。这个 4B 策略里没有外部路由器，模型自己判断这一步走哪个通道：视觉布局、画布编辑、应用里的实时状态，走 computer_use，11 个 GUI 原语加归一化坐标；表格、文档这类结构化编辑，以及做完后的确定性校验，走 bash，一个持久 shell 加 Python 环境。背后的直觉很简单：在菜单里点几十下改一个 xlsx，不如直接用 openpyxl 写文件；但改一张图的视觉效果，脚本写不了。

训练配方有三步值得抄作业的人看。

1. 先修教师 harness 再收轨迹。微软发现强模型拿到冗余工具也会养成坏习惯，而且坏习惯会蒸馏给学生。删掉 xdotool 和冗长的无障碍树这类重复通道、预装领域 Python 库后，GPT-5.4 教师升到 92.0%、步骤少 29.2%，学生对应 +12.5 个百分点（37.6% 对 25.1%）。

2. 题库按技能复用。Mage-CUA-Forge 为每一项原子技能写一次生成工作流，而不是每个任务跑一遍开放式 agent 循环。共产出 293,806 个任务、覆盖 6,915 项技能，单任务生成成本从 0.906 美元降到 0.158 美元，降了 82.6%。

3. 五阶段先分练再合并。视觉 grounding、GUI 执行、终端能力分别训练，再用 Hybrid SFT 学通道切换，最后在线 GRPO 用可验证的任务结果做强化学习：45.56% 到 55.84% 再到 66.0%。在线 RL 这一步加了 10.16 个百分点，同时平均模型调用从 21.57 次压到 18.77 次，输出 token 从 7,374 降到 5,499。

上下文管理上它用非对称滑动窗口：最近 3 张截图和 4 条完整回复保留，更早的历史压成一行 Action 摘要，活动窗口 32K token。4B 权重 bf16 约 9.48 GB，Apache-2.0 许可。

七种 multi-agent 分工模式

Alex Prompter @alex_prompter

Picking the wrong multi-agent pattern is how teams end up with agents that duplicate work, loop forever, or contradict each other. These are seven patterns for how agents split tasks, share information, and combine results.

Start with the simple ones. Parallel has agents work at the same time and merge their results, which fits independent subtasks. Sequential passes each agent's result to the next, which fits multi-step workflows where every stage depends on the one before it.

Then add feedback and routing. Loop pairs a creator with a reviewer, and the work gets revised until it is approved, so it fits iterative improvement. Router uses a routing agent to select the right specialist for each task, which fits task classification and routing.

Next, decide how agents combine their work. Aggregator has a central agent merge several outputs into one, which fits synthesis of several outputs. Network lets agents share information and collaborate as peers with no single owner, which fits shared decision-making.

For larger systems, Hierarchical has a lead agent assign work to specialists, who report back when they finish. It fits structured team orchestration.

The pattern you pick should match the task: split, chain, refine, route, combine, collaborate, or delegate.

Bookmark this before you design your next agent system and default to one agent doing everything.
