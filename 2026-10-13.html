decidr 的作者 Anmol Sharma 做了个 learnc，把 C 代码里那些手挑的常数交给梯度下降去学，然后把同一个 C 文件还给你，生产里不留任何新依赖。

《learnc：自动调优你 C 代码里的魔法数字》

每个 C 代码库里都塞满了手挑的常数：阈值、表、权重、截止值。learnc 从数据里把这些常数调出来，再把同一个 C 文件还给你，只是数字更好了。不用重写，不在生产里跑运行时库，也不塞神经网络。只是一个更小的 diff。

learnc tune score.c --data https://examples.pt/ --tune encoder.h:YQT,UVQT --out tuned/

在真实、未改动的 C 代码上得到的结果

· JPEG 编码器（stb_image_write.h）——调了它量化表里的 128 个数字——在它没见过的数据上：同等画质（SSIM）下文件小 9.1%，mozjpeg 的表是 2.7%。标准 JPEG：每个解码器都会读它 · Google 的 WebRTC 语音活动检测器——调了 vad_core.c 里每一个常数——在 LibriParty 上 F1 从 0.810 到 0.859，准确率从 0.816 到 0.858 · 一个 2×2 矩阵乘——84 个系数——只从样例里就重新发现了 7 次乘法的 Strassen 型算法 · 排序网络——每一步比较哪些元素——为 4 个和 5 个输入找到可证明最优的网络

每个结果都能在一台笔记本的 CPU 上几分钟跑完，并且可以从 examples/ 目录复现。

输出是你自己的文件，只是数字变了。下面是 learnc 给 Google 的 WebRTC VAD 写出的 diff 开头。

为什么做 learnc

· 作用在你已有的代码上。按名字指向常数：文件级的、函数里的 static、或者头文件里的。你的文件永远不动，调完的副本只差那些变了的数字 · 任何能编译的 C 都行。指针、结构体、malloc、文件、qsort 回调、sscanf、没有源码的库。clang 和 gcc 能构建的，learnc 就能调 · 优化你真正在意的东西。你的评分函数返回一个数：错误率、文件大小、延迟、与预期输出的匹配度。learnc 去最小化它 · 生产可用。带早停的留出验证、一个把你拉回原值的力，以及最后一轮把所有没帮上忙的改动回退掉。diff 里只留下有意义的改动 · 零运行时开销。输出就是带常数的纯 C。用任何编译器、在任何平台都能发

用途

· 压缩：JPEG 与 WebP 的量化表、zlib 匹配参数、编解码器的码率控制常数 · 音频与信号处理：语音活动检测阈值、降噪、滤波器系数 · 启发式：缓存大小、排序与查找的截止值、评分权重、重试与退避常数 · 控制：PID 增益、物理与仿真参数 · 嵌入式和定点代码：Q 格式常数按整数调，保持原有类型 · 用 C 写的小模型：规则、决策结构，以及能编译成零依赖 C 的小网络

安装

pip install learnc

还需要系统里有 clang、llvm-link 和 gcc：

sudo apt install clang llvm gcc # Debian / Ubuntu brew install llvm gcc # macOS（把 $(brew --prefix llvm)/bin 加进 PATH）

Python 3.10 起。PyTorch 和 NumPy 会一起装上。要改 learnc 本身：

git clone https://github.com/devanmolsharma/learnc && cd learnc pip install -e ".[dev]" && pytest

快速上手：调已有代码

1. 看看有什么能调：

learnc constants encoder.c --cflags "-I include"

2. 写一个评分函数，接一个样例、返回一个要最小化的数，或者一个要匹配的结果：

#include "encoder.h"
