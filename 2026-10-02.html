你现在可以定制自己的 Claude Code 了：

包括改UI界面、拦住危险命令、逐步查看代码改动

Claude Code 中的 Mods 升级：它允许通过 JavaScript 或 TypeScript 模块重写或替换部分行为，甚至绘制自定义 UI。

Claude Code 的 Mods 是会话内运行的小插件，让你按自己的工作习惯定制行为和界面：

输入框上方多一行用量：比如你可以这样描述需求：“在输入框上方加一行上下文用量，快满时变色，显示最近变化”。Claude 生成这个 Mod，你允许在当前会话热重载（保存代码即可生效）后，输入框上方就会出现一行每轮更新的用量显示；你若接着说“把暴风雨门槛从 75% 改成 70%”，保存修改后的代码，新的阈值就会生效。

删文件前，先看清会删什么：装上 Blast Radius 后，在执行删除 build 目录前，界面会打开面板，列出将删除的文件和占用空间，等待你按下数字键选择 Proceed 继续或 Cancel 取消。

改完后，逐项看哪里变了：装上 Replay Theater 后，一轮交互改完多个文件，输入框上方就会出现回放提示；只需按下 r 键或输入 /replay，即可在侧边面板逐项翻看每次编辑前后的差异（diff）。看完关闭面板即可，文件保持修改后的状态。

As a DevRel, this one hits close to home. My whole job is turning dense technical stuff into something people actually get.

The ASD-STE100 trick is new to me, and it makes a lot of sense. It's the controlled English written for aircraft maintenance manuals, so crews who aren't native English speakers can't misread a step. As someone who works in two languages every day, I'd love more docs written that way.

One thing I'd add. If more of our work moves up into oversight, the hard part isn't only understanding one output. It's keeping track, across a hundred of them, of what the agent did, why it did it, and what you already signed off on.

The web apps and explainer videos can be throwaway. What you learned from them needs to stick around somewhere.
