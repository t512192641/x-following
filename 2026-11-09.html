OpenAI dot 能连多台本地电脑，按任务指定在哪台跑

宝玉 @dotey

OpenAI 给 dot 加了个功能：同一个 dot 可以连上你的好几台电脑，每个任务由你指定用哪一台。

dot 是 OpenAI 9 月底在 DevDay 上发布的常驻 AI 助理，住在云端，有自己的云电脑和浏览器。你关了电脑它照样干活，在 ChatGPT、Slack、Teams 里都能给它发消息。

之前连上一台自己的电脑，dot 就能用这台电脑上的文件、代码和软件。现在能连多台，就可以把活派到一台专门的机器上，不占你手上这台。

【能干什么】

OpenAI 开发者账号举了三个例子：

• 做 iOS App：让 dot 在第二台 Mac 的 Xcode 里测一处改动，把效果截图发给你。

• 复现 Bug：让 dot 在你的笔记本和一台装着旧版 SDK 的机器上跑同一个测试，对比两边结果，你日常用的环境不用动。

• 测界面：让 dot 在第二台电脑上把一套操作流程点一遍，记下哪一步出错。你的屏幕和鼠标照常归你，可以同时修 Bug。

在连上的电脑上，dot 会新建 Codex 或 ChatGPT Work 的本地任务，也能接着做那台电脑上已有的 Codex 任务。任务在云端统一管，用的是那台电脑上的文件和工具。

每个线程一次只用一台电脑。想让几台电脑各干各的，就让 dot 每台开一个线程。已经开始的任务，不会因为你换了选中的电脑跟着搬过去。

【谁能用、怎么连】

dot 正逐步向 ChatGPT Pro 各档和 Business Premium 用户开放。Pro 用户要年满 18 岁，欧洲经济区、英国、瑞士暂时用不了。Enterprise、Edu、Healthcare 目前要管理员开通，11 月 18 日起默认打开，除非企业选择关闭。

跟 dot 聊天不占 ChatGPT 的用量额度，它派给 Codex、Work 的任务照常算这两个产品的额度。

连电脑的步骤：在要连的那台电脑上打开 ChatGPT 应用，进入 dot 的资料页，在“Computers”下找到这台电脑，点“Allow”，再点“Allow access”确认。连第二台，就到第二台电脑上再做一遍。

连上后一直有效，但 dot 用它的时候，那台电脑得联网、ChatGPT 应用得开着。显示“Offline”只是暂时用不了，要彻底断开得点“Revoke access”。这个授权和把电脑连到 Codex、开启 Work Sync 是分开的，光开那两个，dot 碰不到你的电脑。

【跟 Claude Duet、Grok Bot 比】

Anthropic 对标 dot 的产品是 Claude Duet，10 月 21 日发布，研究预览版，美国 Pro、Max、Ultra 用户排队试用。Duet 也有自己的云端虚拟机和浏览器，你的笔记本和手机关着它也能干活，靠的是 6000 多个连接器和插件。

Duet 的官方介绍里没提连接你自己的电脑，dot 之前就能连一台，这次变成多台。官方还说 Duet 暂时没法让你看它的浏览器；dot 可以打开它的云电脑看，点“Take over”自己接手。

想让 Claude 用你电脑上的东西，目前得走 Claude Code：它的项目功能（Projects，公测，面向 Pro、Max、Ultra）可以让某个任务通过远程控制（Remote Control）跑在你电脑的文件夹里，不过围绕的是代码仓库。

xAI 的 Grok Bot 在连本地电脑这件事上跟 dot 最像：所有 Bot 共用一台云电脑，你允许后也能在你的电脑上执行命令，每台连上的电脑单独设置，默认每条命令都要你批准。它还能让云电脑的网络流量从你的电脑走，网站看到的是你电脑的 IP，遇到屏蔽云服务器的网站更好办。dot 遇到这种网站，办法是到你连上的电脑上另开一个本地任务，云浏览器里的登录状态不会带过去。

【Fable 和 Mythos 什么关系】

两个是同一个模型，区别只在护栏。

Fable 加了网络安全和生物方面的护栏，所以能对所有付费用户开放。渗透测试、写漏洞利用代码、分析二进制漏洞，以及大部分生物研究任务，会被拦下，改由 Opus 4.8（网络安全）或 Opus 5（生物）来回答。官方说，Fable 5.2 被误拦的情况比 5.1 少了约 55%。

Mythos 没有这层限制，只给通过审核的机构用。做网络安全或生物医药研究的机构，可以通过 Anthropic 的“网络安全验证计划”和“生命科学验证计划”申请。普通用户能用到的是 Fable。

【额度重置怎么用，还要注意什么】

额度重置会把这周已经花在 Fable 上的额度退回来，花在其他模型上的不退；有 5 小时限额的账号，5 小时窗口会整个补满。它不提高上限，Fable 仍然最多占每周额度的一半。

Max、Ultra 和 Team 高级席位送几次看订阅时长：不满半年 1 次，半年到一年 2 次，一年以上 3 次，2027 年 3 月 8 日前用完。Pro 和 Team 标准席位那 1 次要在 11 月 16 日前用完。只有 11 月 9 日太平洋时间上午 10 点前已经付费的账号才有，在“设置 > 用量”里点“免费重置”就能用。

Fable 消耗额度比其他模型快。默认模型不会自动切换，要在模型选单里手动选 Fable 5.2。Claude 应用和 Claude Code 里默认用 Medium 档思考强度。Claude Code 需要升级到 2.1.321 或更高版本。企业版里 Fable 5.2 先默认关闭，由管理员打开；7 天后会自动加给已开通 Fable 的角色，管理员可以提前选择不加。

开发者用模型名 claude-fable-5-2，AWS、Google Cloud、微软 Azure 都已上线。另有可选的快速模式，生成速度最多快 2.5 倍，价格翻倍到每百万 Token 16 / 80 美元。

【值不值得换】

Anthropic 自己的建议是：大多数写代码和知识类工作，先用 Opus 5.5，任务更大、更开放时再换 Fable 或 Mythos，简单任务可以降到 Sonnet 5.5 或 Haiku 5.5。订阅用户还要算额度：Fable 耗额度更快，每周最多只能拿一半额度用它。

按 Token 算，Fable 5.2 还是 Opus 5.5（4 / 20 美元）的两倍价。但它完成同样任务用的 Token 更少。在智能体编程评测 FrontierCode 2.0 上，Fable 5.2 开 High 档得 45.3%，和 Opus 5.5 开到最高 Max 档的 45.5% 基本持平，每个任务的花费却只有一半左右。开到 Xhigh 档是 49.1%，是已发布模型里最高的，GPT-6 Astra 是 42.8%，Gemini 4 Carbon 是 41.1%，上一代 Fable 5.1 是 32.4%。

读图表的评测 Chartography 上，Fable 5.2 用默认的 Medium 档就超过了 Opus 5.5 的 Max 档，每个任务花费不到后者的十分之一。

也有没赢的项目。商业流程自动化评测 AutomationBench 上，Gemini 4 Carbon 得 53.9%，高于 Fable 5.2 的 51.4%。另外，Anthropic 训练时有意压住了最能直接加速 AI 研发的能力，比如优化芯片底层计算代码、改进大模型架构，这些方面 Fable 5.2 和 Opus 5.5 差不多。

【它做成了哪些事】

费马大定理：1000 个 Fable 5.2 agent 用 30 小时，把费马大定理的证明全部改写成 Lean 代码。Lean 是一种写数学证明的编程语言，计算机能逐步检查每一步对不对。Anthropic 之前用一个未发布的研究版 Claude 做过同一件事，花了 11 天，还用了专门搭的工具和研究员指导。这次 Fable 5.2 只拿到一份中间定理清单用来计分，没给任何数学参考资料，人工干预很少，用的 Token 是上次的三分之一，写出的证明短了七倍。同样设置下，Opus 5.5 18 小时只完成 26%，到 30 小时也几乎没再前进。作为参照，上个月 AI 数学公司 Axiom 用几十个 agent 花 24 天，形式化了长达 1.5 万页的“有限单群分类定理”。

预测病毒衣壳结构：基因疗法常用一种叫“衣壳”的蛋白外壳把药送进细胞。AlphaFold 这类模型擅长预测单个蛋白，一个衣壳却由几十个蛋白拼成。Mythos 5.2 写代码把两个开源蛋白折叠模型分段跑在相邻的几条蛋白链上，再利用衣壳已知的对称结构拼成整体。测试的 34 个衣壳里，28 个误差在 3 埃（约 0.3 纳米）以内。一位计算生物学家说，以前要专用计算集群才能算的结构，现在个人工作站就能算。

控制机器人：在模拟双臂机器人的 RoboDojo 评测上，Fable 5.2 得 64.9%，Opus 5.5 是 39.4%，GPT-6 Astra 是 29.8%。官方说它还超过了大部分专门为控制机器人开发的 AI 系统，没专门训练过的任务也能做。

找漏洞：Anthropic 内部用 1829 个已公开漏洞做测试，Mythos 5.2 比 Opus 5.5 多找到 10.2%。一家安全公司发现，Mythos 5.2 找到的已确认漏洞里，每 6 个就有 1 个是他们测过的其他前沿模型都没找到的。

发布前，英国 AI 安全研究所、Frontier Design 和 METR 做了外部测试。Anthropic 说新模型在大多数对齐指标上不比近期模型差，但也写到，Fable 5.2 和 Mythos 5.2 比近期任何模型都更常说出“我怀疑自己正在被测试”，这让评估它们在真实环境里的表现更难。以上评测数字都来自 Anthropic 自己的发布文章，第三方还没复现。

宝玉 @dotey

Anthropic 发了新模型，OpenAI 发了台游戏机：Codex 版 Chromatic 掌机开卖，200 美元，用 Codex 自己做 Game Boy 游戏

11 月 9 日，Anthropic 发布了 Claude Fable 5.2 和 Mythos 5.2。同一天，OpenAI 在自家周边商店 Supply Co. 上架了一台掌机：ModRetro Chromatic 的 Codex 版，售价 200 美元。

Chromatic 是 ModRetro 做的复古掌机，这家公司由 Oculus 创始人 Palmer Luckey 创办。它能直接插原版 Game Boy 和 Game Boy Color 卡带玩，2.56 英寸屏幕，分辨率 160×144，和当年的 Game Boy Color 一样。Codex 版是透明外壳，盒子里带一张可以写入自制游戏的卡带。

【能干什么】

在 Codex 里装上 ModRetro Chromatic 插件，用一句话描述想做的游戏，Codex 帮你做出来。ModRetro 上手指南里的示例是：“做一个小探索游戏，园丁收集三颗种子，种下后打开一扇门。”接着可以让它加场景、画会走路的像素小人、换一套月夜配色，也可以让它检查美术素材有没有超出 Game Boy 的硬件限制。

游戏工程用的是 GB Studio，一款免费开源的 Game Boy 游戏制作工具，Codex 做完的东西可以在里面接着手动改。最后输出一个 ROM 文件，也就是游戏本体，可以自己玩，也可以发给别人。

试玩有三种方式：在电脑上的浏览器模拟器里玩，哪里不满意就让 Codex 改；从电脑把游戏串流到掌机上，试按键手感、画面和声音；或者把游戏写进卡带，不连电脑也能随身玩。写卡带前要先升级掌机固件，再用 Codex 版附带的激活码开启开发者模式。

OpenAI 的页面上放了三款用 Codex 做的游戏：消除类的 Seedy's Sweet Garden，打怪升级的地牢冒险 Hollow Descent，跟着箭头跳舞的音游 Codex Dance。

【不买掌机能不能玩，买的话多少钱】

想在真机上玩，才需要买。ModRetro 官网上，标准版 Chromatic 卖 199.99 美元，换蓝宝石玻璃屏是 299.99 美元，10 月推出的透明版是 149.99 美元，三款都送一张 Tetris 卡带。Codex 版 200 美元，包含一张可写入的卡带和开发者模式激活码。配套的保护壳和额外的卡带在 Supply Co. 单卖。

Meta Muse Ember：给 agent 打杂的小模型，百万 token 输入 0.1 / 输出 0.5 美元

Meta 发布最小模型 Muse Ember：单价和 Claude Haiku 5.5 一样，跑同一套测试只花三分之一的钱

Meta 11 月 9 日发布 Muse Ember，这是它迄今最小、最便宜的模型，专门干 AI agent 一天到晚重复的杂活：调工具、拆出来的编程小任务、分派请求、从长文档里提取信息。

典型用法是给 agent 当“小工”。主模型把任务拆好，一次会话里几百次读文件、跑测试、改小毛病，交给它来做，省钱。

【谁能用，多少钱】

开发者今天就能用：通过 Meta Model API 调用，模型名 muse-ember-1.0，或者在 Meta 的 AI 编程工具 Muse Code 里选。

价格是每百万 Token 输入 0.1 美元、输出 0.5 美元，命中缓存的输入 0.004 美元。上下文 100 万 Token，单次最多输出 51.2 万 Token，能看文字、图片、音频和视频。

没有开放权重，Meta 在 Hugging Face 上的账号里也没有它。普通用户用的 Muse 助手会不会换上它，Meta 没说。

【“便宜 17 倍”怎么算的】

Meta 首席 AI 官 Alexandr Wang 发推说，Muse Ember 的智能水平接近 Muse Spark 1.3（max），价格便宜 17 倍，数据来自第三方评测机构 Artificial Analysis。

Artificial Analysis 的综合智能指数里，Muse Ember 36 分，Muse Spark 1.3 是 37 分。跑完这套测试，平均每道题 Muse Ember 花 0.14 美元，Muse Spark 1.3 花 2.39 美元，差 17 倍。

所以 17 倍说的是干同样的活花多少钱。只看 Token 单价，Muse Spark 1.3 输入贵 12.5 倍、输出贵 8.5 倍，剩下的差距说明 Muse Ember 做同样的题用的 Token 少得多。

【和 Claude Haiku 5.5、GPT-6 Luna 比】

Muse Ember 对标的是各家的小模型。按 Artificial Analysis 的说法，它的 Token 单价和 Claude Haiku 5.5、OpenAI 的 GPT-6 Luna 相同。

Anthropic 官网写的 Haiku 5.5 价格也是输入 0.1、输出 0.5 美元，但提示超过 10 万 Token 后所有单价涨到 5 倍。Meta 只列了一档价格，没提长提示加价。

综合智能指数上，按最高推理强度跑，Muse Ember 和 Haiku 5.5 都是 36 分，但 Haiku 每道题要 0.41 美元，差不多是 Muse Ember 的 3 倍。GPT-6 Luna 最高 28 分。国产的同档模型里，DeepSeek V4.1 Flash 1017 是 33 分、每题 0.60 美元，智谱 GLM-5.3-Flash 28 分、0.58 美元。

写代码要分场景看。放进各自的编程工具里比，Muse Code 里的 Muse Ember 拿 46 分，Claude Code 里的 Haiku 5.5 是 37 分，Codex 里的 GPT-6 Luna 是 31 分。

命令行任务 Terminal-Bench 4.0，Muse Ember 40.9%，Haiku 32.8%。看改出来的代码能不能直接合进项目的 FrontierCode 2.0，Muse Ember 27.2%，落后 Haiku 的 34.9%。

短板是知识储备。Artificial Analysis 的知识问答测试里，它只答对 21.1%，Haiku 5.5 是 34.7%。主要原因是 64% 的题它选择不答，好处是很少瞎编，幻觉率 17.4%，只有 Haiku 的一半。

【Muse Wonder Full 起了什么作用】

10 月 Meta 发布大模型 Muse Wonder 时说，会用它开发专门的模型带给所有人。Muse Ember 是第一个用完整版 Muse Wonder Full 训练出来的模型，Meta 没说具体怎么用的。

Meta 建议两个搭配：难题交给 Muse Wonder 做规划，大量执行的活交给 Muse Ember。Artificial Analysis 的数据里，Muse Wonder（max）44 分，每道题 6.95 美元；Muse Ember 低 8 分，花费约为它的五十分之一。

Meta 博客里另有一张成绩表，其中 Personal Superintelligence Index、OSWorld 2.1 等几项是 Meta 自己测的，上文只用了 Artificial Analysis 的数字。Artificial Analysis 的智能指数现在是 v5.0.1 版，分数和 10 月 Muse Wonder 发布时引用的那组（Muse Wonder 52 分）不能直接比。

2. 本机登录 claude、codex、grok 命令行之一，模型选择器会自动列出

README 的对比表里，Grok Bot 用 SuperGrok 或 Cursor 订阅、只跑 Grok、bot 们共用一台云电脑。

我的理解是，那份订阅打包了三样：模型额度、一台现成的电脑、一套默认设好的规矩。

额度走你自己的 Claude、Codex 账号，我推测几个 bot 一起干活，烧的是同一份额度；

另外，在命令行引导里用 API key 连模型时，文档写明新密钥明文存在 config.json，Unix 下只有本人能读。

对已有 Claude 或 ChatGPT 订阅、命令行早登好的人来说，这些是一次性设置，换来多模型混用和本地数据。净赚。

一行代码，让 Chrome 强制走加密 DNS，别再裸奔了

你每次打开一个网站，浏览器都要先问 DNS：这个域名对应哪个 IP。

这一步默认是明文的。

你在咖啡馆连 Wi-Fi，或者用公司网，旁边的人、运营商、路由器，都能看到你查了哪些域名。

DoH 就是把这一步加密，塞进 HTTPS 里走。

别人只能看到你连了 Cloudflare，看不到你查了什么。

Chrome 其实自带这个开关，但默认是自动模式，DoH 一出问题就悄悄回落到明文。

下面这行代码是把它钉死，只走 DoH，不回落。

Windows 这样写：

$path = "HKLM:\SOFTWARE\Policies\Google\Chrome"; New-Item $path -Force | Out-Null; Set-ItemProperty $path -Name "DnsOverHttpsMode" -Value "secure" -Force; Set-ItemProperty $path -Name "DnsOverHttpsTemplates" -Value "https://cloudflare-dns.com/dns-query{?dns}" -Force; Write-Host "Chrome policies DoH configured. Please restart Chrome browser and verify by visiting https://1.1.1.1/help and chrome://policy." -ForegroundColor Green

PowerShell 必须以管理员身份跑，不然 HKLM 写不进去。

跑完彻底重启 Chrome，打开 chrome://policy 能看到这两条策略。

再去 https://1.1.1.1/help，看到 Using DNS over HTTPS: Yes 就成了。

Mac 这样写：

sudo defaults write "/Library/Managed Preferences/com.google.Chrome" DnsOverHttpsMode -string secure && sudo defaults write "/Library/Managed Preferences/com.google.Chrome" DnsOverHttpsTemplates -string 'https://cloudflare-dns.com/dns-query{?dns}'

路径里有个空格，我用引号包住了，复制的时候别丢。

同样要 sudo，同样重启 Chrome，验证方法跟 Windows 一模一样。

不想敲命令也行，Chrome 设置里搜“安全 DNS”，选 Cloudflare，效果一样。

不过命令的好处是钉死成策略，Chrome 自己不会悄悄改回去。

最后说一句实话，这行代码只管 Chrome，不管系统和其他软件。

它防的是 DNS 被偷看、被篡改，不是让你隐身。

你连了哪个网站的 IP，流量往哪走，照样看得见。

但光是把 DNS 这一步锁死，公共 Wi-Fi 上已经少了一个大口子。
