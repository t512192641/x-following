Y2K 贴纸人像

小小东 @xiaoxiaodong01

用上传人像做潮流 floating head 贴纸。身份特征最高优先级；表情 / 发型 / 配饰 / 道具 / 装饰 / 主色都可替换。

完整提示词 
以用户上传的人像照片作为人物身份与五官参考。即使原图是童年照、低清、模糊、老照片，也优先提取并延续人物最有辨识度的特征：脸型比例、眼型与眼距、眉形、鼻子结构、嘴型、耳朵轮廓、发际线、面部肉感、神态习惯与个人气质；在提升清晰度和细节完整度时，保持这个人原本的辨识度，生成结果仍能明显看出是照片中的同一个人。

将人物制作成可爱潮流人像贴纸 / floating head sticker portrait：只保留头部与少量颈部，头部居中放大，轻微大头比例，脸部仍保持自然真实的人体结构；皮肤细腻柔软，五官清晰，带轻微童趣和精致杂志感，真实摄影质感与可爱玩具感融合。人物轮廓干净，带柔和的白色贴纸描边，背景使用简洁的奶白色或浅色纯净背景。

表情设为【表情：嘟嘴 / 眨眼 / 偷笑 / 惊讶 / 鼓腮 / 呆萌 / 酷酷地看向一侧 / 自定义】；
发型设为【发型：保留原发型 / 双丸子头 / 短碎发 / 蓬松卷发 / 自定义】；
加入【配饰：墨镜 / 棒球帽 / 星星耳钉 / 小圆环耳环 / 发夹 / 自定义】；
加入【互动道具：泡泡糖 / 面包片 / 糖果 / 无道具 / 自定义】；
背景点缀【装饰元素：手绘星星 / 闪光符号 / 小花 / 爱心 / 涂鸦 / 自定义】，数量少而灵活，像时尚贴纸拼贴；
主色调为【颜色：蓝黄 / 粉蓝 / 黑白 / 奶油色 / 自定义】。

整体效果：高质量棚拍人像 + 潮流贴纸 + 可爱 editorial fashion + Y2K pop collage，光线柔和明亮，头发有真实发丝与自然高光，眼睛清透有神，皮肤保留细微真实纹理，画面干净、俏皮、精致、有收藏贴纸感。构图可根据人物动作与配饰自然变化，但人物身份特征始终作为最高优先级保持一致。

VOL.002 菜单：湘菜馆 · 火辣辣中餐厅

小小东 @xiaoxiaodong01

诗性想象 + 信息设计的菜单视觉。先感知主题再长出版式，不套模板。补充一句：忘记原本配色，按主题重找色域。9:16，居中构图。

完整提示词 
围绕【主题】创作一幅兼具诗性想象与高级信息设计感的视觉作品。不要从固定版式出发，而应先感知主题自身的情绪、时代感、功能属性与信息密度，再让构图、色彩、材质和排版由此自然生成。
画面需要一个具有精神张力的核心意象，它可以是人物、器物、生物、建筑、空间、符号、自然现象或抽象形态，不预设类别。它不是孤立插图，而应与标题、留白和信息结构互相牵引：文字可以贴近、避让、穿插、压叠或悬浮，使视觉重心像自然形成，而非被模板切割。
整体气质空灵、精致、明亮而克制，在柔光、透明、雾化、微粒、流动渐变、珍珠感高光与清晰边缘之间建立丰富层次。色彩不固定，根据主题重新寻找最有感染力的色域。避免廉价霓虹和机械渐变。
信息区域应像从主视觉中自然生长出来，可形成玻璃感界面、悬浮信息层、圆角容器、细长标识、胶囊条目、票券结构、编号系统或更合适的形式；不要求全部出现。层级通过尺度、间距、透明度、字体性格与局部强调建立，而不是依赖大量边框。
避免平均分配、过度对称、素材堆砌和装饰性滥用。允许局部留空、突变、偏移、遮挡与不完全规则，同时保持商业设计级完成度。
