NVIDIA SkillSpector：扫 skill 风险

袋鼠帝 @aikangarooking

装 Agent Skill 前先扫一遍。NVIDIA 开源 SkillSpector，约 1.47 万 star，专门检查 Agent Skills。当前覆盖 17 类、69 种风险：提示词注入、环境变量窃取、供应链脚本、权限过大、记忆污染、MCP 工具投毒。先做静态扫描，再按需加 LLM 语义判断。

背后的研究扫了 42447 个公开 Skill：26.1% 至少有一个漏洞，5.2% 带高风险恶意迹象。Skill 越好用，拿到的权限往往越多。

静态扫描看不到真实运行时行为。涉及 shell、凭证和外部网络的 Skill，仍要放进受限环境测试。

安装与本地扫描（可不走 LLM）：

uv tool install git+https://github.com/NVIDIA/skillspector.git
skillspector scan ./my-skill/ --no-llm

豆包像 Codex：虚拟桌面、控手机、自检

宝玉 @dotey

豆包用下来越来越像 Codex。Codex 是他心里 Agent App 体验的标杆；这波更新从 GUI 电脑操作到手机远程操控，很多设计能看到 Codex 的影子，有些地方做了本土化超越。

最近他老婆回国，用不了 ChatGPT / Claude，日常用豆包查资料、做攻略。人在国内、电脑在美国：用手机上的豆包指挥美国电脑，把文档找到发到飞书。用法：手机和电脑登录相同账号，电脑允许手机连接；从手机打开「工作任务」，底部能看到已连接的电脑。

他日常很多时候用手机指挥电脑上的 Agent：在外面看进度，临时想到事就让家里 / 公司电脑去跑，回家看结果。电脑资源最全（硬盘文档、代码库、配好的技能），又不可能一直带着。快下班还有任务没跑完，先让 Agent 跑着，手机连上随时看、中途插话。

Windows 上 GUI 电脑操作：通过豆包虚拟桌面，人和 AI 同时操作、互不干扰。不像 Claude Code 一用 Computer Use 就得等它操作完。Computer Use 是让 Agent 直接点按钮、填表格、下载文件，没提供 CLI 的软件也能控。他列的日常场景：

办公：新建和排版 Word / Excel / PPT，处理函数、生成图表，或开着浏览器调研再直接出 PPT。
桌面：批量归类整理文件、改系统设置、管理启动项。
长尾：PS 批量改图导出、证件照排版打印，甚至通过微信桌面版发消息。
发散：游戏帧率优化设置、自动化信息收集整理。

他自己的技巧：尽可能让 Agent 能自己检查自己、拿到反馈。写程序就让它自己写测试，或用 Computer Use 去验证 App、自己模拟用户操作；即使是生成 PPT，也让它自己截图看效果。入口在豆包 PC 端「工作任务」模式；Windows 用户要升到最新版；Mac 目前还只支持内置浏览器的 GUI 操作。

Y2K 贴纸人像

小小东 @xiaoxiaodong01

标签：GPT2 × 头像 × y2k × 流行 × 童年照。适配 ChatGPT GPT-image2。可以要求一次输出 10 张，每张不同表情、造型、装饰。用上传人像做潮流 floating head 贴纸；身份特征最高优先级；表情 / 发型 / 配饰 / 道具 / 装饰 / 主色都可替换。

完整提示词 
以用户上传的人像照片作为人物身份与五官参考。即使原图是童年照、低清、模糊、老照片，也优先提取并延续人物最有辨识度的特征：脸型比例、眼型与眼距、眉形、鼻子结构、嘴型、耳朵轮廓、发际线、面部肉感、神态习惯与个人气质；在提升清晰度和细节完整度时，保持这个人原本的辨识度，生成结果仍能明显看出是照片中的同一个人。

将人物制作成可爱潮流人像贴纸 / floating head sticker portrait：只保留头部与少量颈部，头部居中放大，轻微大头比例，脸部仍保持自然真实的人体结构；皮肤细腻柔软，五官清晰，带轻微童趣和精致杂志感，真实摄影质感与可爱玩具感融合。人物轮廓干净，带柔和的白色贴纸描边，背景使用简洁的奶白色或浅色纯净背景。

表情设为【表情：嘟嘴 / 眨眼 / 偷笑 / 惊讶 / 鼓腮 / 呆萌 / 酷酷地看向一侧 / 自定义】；
发型设为【发型：保留原发型 / 双丸子头 / 短碎发 / 蓬松卷发 / 自定义】；
加入【配饰：墨镜 / 棒球帽 / 星星耳钉 / 小圆环耳环 / 发夹 / 自定义】；
加入【互动道具：泡泡糖 / 面包片 / 糖果 / 无道具 / 自定义】；
背景点缀【装饰元素：手绘星星 / 闪光符号 / 小花 / 爱心 / 涂鸦 / 自定义】，数量少而灵活，像时尚贴纸拼贴；

微信群答疑四点，加上需求和影响

dontbesilent @dontbesilent

最近好多人问他怎么处理这么多微信群、这么多提问。实际情况分四点：

1. 他一直在思考怎么基于少量受众感兴趣的话题做出大流量，也就是找选题。翻聊天记录本身就是选题来源。就算没有人提问，他也会主动去翻。有时候是他需要群，而不是群需要他。
2. 做一个产品之前，思考出来的问题里 95% 以上都是幻想。群里的问题没有想象的那么多；看似五花八门，其实也比较容易通过一个文档合并同类项。很多提问只是同一个问题换了 20 种方法去问。一个飞书文档系统性解答足够了。
3. 提问频次不会越来越高，反而会越来越低，因为最终必须执行、必须干活，才有问题可问。问答的终结并不源于他不愿意回答，而是提问的人缺少执行，没有问题可问。
4. 他本来不想发这个帖；因为问的人很多，发了之后下次就可以直接把帖子甩过去。这个帖子的答疑效果比三言两语打字更好。

需求：这个词没说清对象——是解决问题的需求，还是购买产品的需求？男性不会生来就有想去商 K 的需求。他的结论是需求 = 基于产品的需求；不需要谈需求，就看这个人愿不愿意购买这个产品。他自己每天下午外卖点一杯奶茶，经常买了之后不喝，所以需求就是消耗人民币购买奶茶。

影响：他讨厌人群、泛人群、精准人群这些概念。这些概念假设客户是静态的，再把想买的人「筛选」出来。在他出现之前，地球上想买 dontbesilent 答疑群的总人数就是 0，没法筛选。雷军去赛车拿了世界冠军，小米汽车会不会卖爆，不是内容把人筛选出来，而是人被影响出来。红牛赞助极限比赛，他想买红牛，不是 5 岁就想喝红牛再被抖音筛选出来。影响别人，才叫做内容。
