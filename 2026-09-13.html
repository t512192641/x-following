yibie 译：Agent 能做的、与写代码无关的有用之事

yibie @yibie

作者：Elijah Potter（Automattic 工程师） 现在的讨论都在说，让 AI coding agent 写代码能做出多妙（以及多可怕）的事。让 agent 把整个应用的代码全部写出来的人，常被称为「vibe coder」。这篇文章不讲 vibe coding，讲的是 agent 除了写代码之外能做的事。 每个用例，我都会先讲要解决什么，然后附上我在用的 pi prompt 最新版。 我不认为你应该一字不差地照抄我的 prompt，也不建议你复制我的工作流。这些工具的美妙之处在于灵活，可以适配你自己的做法。我把 prompt 当作灵感：也许有些事你也可以交给 agent，而那些事不是写代码。

修 merge conflict 我经常要修自己 PR 的 merge conflict，因为我自己或者开源贡献者在上游改了代码。几乎每次，冲突都出在格式化或样板改动上，根本不需要我全神贯注。换句话说，这是完美的 clanker 活。 做法是用 gh 命令 checkout 这个 PR，然后执行 merge。在我有机会自己审查之前，不要 push 你的改动。在 pi 里可调用：/fix-pr-conflict #4222

找相关的 issue 做开源时想知道自己是不是顺手也解决了别人的问题。可用 pi 命令 /fd-issue 找出相关 issue：是否解决、链接、谁写的。

GitHub Actions 失败 Actions 失败时 90% 不是 bug，而是忘了跑 formatter/静态分析。可用 /diagnose-action-failure 诊断并给出修复计划（需批准再实施）。

所以张一鸣不接受蒸馏这种无限逼近教师模型而无法真实超过的路线，虽然部分从业者并不认同。
