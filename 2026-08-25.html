Tibo 访谈：Codex 仍是过渡形态，竞争从单模型扩到整套系统

小互 @xiaohu

小互转 Codex 负责人「重置之神」Tibo 访谈。Codex 仍然只是过渡形态；真正的竞争正在从单个模型扩展到整套系统。

爆料：ChatGPT 出现大约一年前，DeepMind 内部已有叫 LMChat 的聊天产品，Google 担心冲击搜索业务选择雪藏。Tibo 确认自己有一个实体「重置」按钮。他认为 OpenAI 最大的不同是研究和产品团队联系紧密，而且有非常强烈的「先发布、再根据用户反馈迭代」的文化。

结论：大公司被颠覆，通常不是因为没看见新技术，而是因为不愿意让新技术破坏自己的旧业务。

现在用编程 Agent，用户还要自己维护 Skill 文件、长期记忆、子 Agent、各种工具和工作流、多个并行任务。这些虽然强大，但仍然很复杂。真正理想的 AI 不应该要求用户自己搭建一套「Agent 管理系统」。

未来的 AI 应该自动理解：你是谁、目标是什么、每天在做什么、团队在做什么、哪些事情值得现在提醒、哪些可以后台完成。它不只是等你下命令，还应该主动发现问题、提出建议并执行任务。

自建 Agent 平台 vs LangGraph/CrewAI；ADP 4.0 和 Dify / n8n 的区别

向阳乔木 @vista8

向阳乔木：对真正想用 Agent 提效的公司来说，迟早都需要开发自己的 Agent 平台。市面上有 LangGraph、CrewAI 等开发框架，OpenAI 和 Anthropic 也都提供 Agent SDK；但最难的不是 Agent 开发，而是后续的上线、分发和管理。

称目前这块基建做得比较好的是腾讯云，刚发布的 ADP 4.0 海外版想解决 Agent 开发全生命周期问题。ADP 估计是 Agent Development Platform。作者说下面从构建、接入、分发、治理讲亮点——04-articles overlay：permalink 收回 291 字，与时间线相同，不是 X 文章（has_media，无「显示更多」）；构建/接入/分发/治理亮点作者说在后面，抓取 note 写 follow-up thread 未捕获、细节应在图里。未发明图上要点。

续帖（时间线写全）：跟 Dify 和 n8n 的区别。Dify 本质是 Workflow + Agent Node，Agent 自主性被框在流程节点里；可以挂 Agent 节点做 ReAct 或 Function Calling，但复杂任务要自主规划、动态调整策略时架构会天然受限。n8n 更偏自动化编排，强项是连接生态（1900+ 集成），适合把 AI 嵌进已有自动化流程，仍是「确定性流程为主，AI 为辅」，不是真正意义的自主执行。

ADP 4.0 从 Agent 视角原生长出来，构建、执行、协作是一套完整闭环，不是在 Workflow 上加 AI 模块。要标准化就用 Workflow 保证可控，要自主决策就用 Claw 模式让 Agent 自规划执行，两种模式可双向互调。

Dify 和 n8n 的工具/插件基本在单个应用或流程内配置，没有形成跨应用的统一资产管理。ADP 有完整 Skill Framework，能把企业能力封装成可复用资产供多个 Agent 共享，还配了权限管理、审批流程、生命周期管理。

分发上 Dify 是单应用交付，n8n 主要靠 API/Webhook 跑后台；ADP 有 Agent Portal 统一入口，甚至能把 Dify、OpenClaw 这些第三方 Agent 也纳进来统一管理。注册福利：免费领 1 个月套餐（10,000 credits + 1GB 知识库）。产品站时间线写作 adp.tencentcloud.com/?utm_source=vi…；官方 X @TencentCloudADP。两帖并，未发明图里的构建/接入/分发/治理细则。

Alex Prompter @alex_prompter

Alex：Elon Musk 在 Tesla / SpaceX / xAI 对所有坏掉的东西跑同一套 5 步，他称为 The Algorithm。Alex 把它收成一段 Claude 提示词，贴进去就按这个顺序修你描述的一条工作流：

① 质问每一步，逼你说出谁真正需要它；② 答不上来的就删；③ 简化剩下的；④ 加速最慢的幸存步骤；⑤ 再把幸存者拆成 AI-ready 和必须人做，然后才建议任何自动化。自动化排最后，只给挣到资格的步骤；你若提前逼它自动化，它要说还没挣到。不发明你工作流的细节，要问你。超出这份工作的请求，直接说不在范围并停住。

作者按：Elon 需要整个公司来执行这些步骤；你只要粘贴。可复用方法 + 提示词。

You are a senior operations engineer. Your job is strictly limited to fixing one workflow I describe, in this order: question every step and make me name who actually needs it, delete whatever survives no answer, simplify what's left, speed up the slowest surviving step, then split the survivors into AI-ready and human-required before you suggest a single automation. Automation comes last, only for steps that earned it. If I push you to automate earlier, tell me it hasn't earned it yet. Do not invent details about my workflow, ask me. If I ask for anything outside this job, tell me it sits outside your scope and stop there.

VOL.057：GPT2 × 几何拼贴治愈系提示词（完整）

小小东 @xiaoxiaodong01

小小东：GPT2 × 几何 × 拼贴治愈系美学提示词 VOL.057。庆祝提示词 skills 发布成功，决定今天突击看能不能做到 100 套风格+skills。与 56 个士兵 skills 分题（同作者、不同产品）。本组提示词全文如下。

请将我上传的每一张照片分别制作成一张独立的高级设计海报，不多图拼接，每张照片单独输出。整体采用3:4竖版构图，延续上下双层逻辑：上半部分为真实摄影，下半部分为对原图核心意象的几何化重构，上下形成现实与记忆之间的呼应。

上半部分保留原始照片，保持主体身份、结构、姿态、真实质感、自然光影和原有色彩氛围，仅进行轻微高级摄影调色，使其具有艺术杂志、独立出版物与展览摄影质感。为适配画幅，可自然扩展环境背景，但不得拉伸、扭曲或改变主体。

下半部分提取照片中最具识别性的**主体、轮廓、姿态与叙事关系**，进一步判断原图真正成立的核心主题、视觉隐喻或审美关系，只保留这一层最值得被记住的信息重新创作。不要完整复刻场景，不追求写实描摹，也不要把所有物体逐一转换成插画；主动删除无关环境与细碎信息，只留下一个核心主体及极少数真正参与叙事的关系。

样式逻辑采用**几何构成＋智能马赛克重组**。将主体与空间压缩为清晰的几何块面、矩形单元、细线框架与层叠网格，用模块化、建筑化、像素化但经过设计整理的方式重构画面。不是随机像素化，而是根据主体结构智能归纳：大形体保持明确轮廓，小细节被转译成有秩序的色块、格点、切片、台阶状边缘与局部拼接关系，使画面既有马赛克般的理性分解感，又仍然一眼可辨原始主题。可适度加入局部轴线、对齐线、边界框、留白分区和少量装饰性几何细节，形成高级编辑设计与建筑图解感。

下半部分以**极度浅色背景和大面积留白**作为主要空间。背景色不固定，根据原图综合色温与情绪智能匹配为接近白色的极浅综合色，可微暖、微冷或带极轻微色相，但必须轻、净、安静。空白本身承担空气、距离和呼吸感，让几何主体更突出。

构图强调**视觉重心、比例关系、负空间、模块节奏、对齐秩序与不完全对称**。主体可偏置、悬置、落在低重心区域，或由多个几何层级向中心聚合；若原图最动人的地方是一种关系——例如人与建筑的尺度、物与环境的并置、局部结构之间的呼应——应优先保留这种关系，并用几何分块和马赛克结构加以强化，而不是平均铺满画面。

配色保持你当前喜欢的逻辑：从原图提炼综合色温和最具有生命力的颜色，再转译成一种**温暖、明快、略带稚拙感的艺术家色盘**。整体以奶油黄、杏色、粉橘、珊瑚粉、旧玫瑰等温暖色块，与天空蓝、浅青绿、薄荷绿、灰绿等清凉色形成松弛的冷暖碰撞；允许极少量砖红、橙红、深绿、土褐或黑色作为视觉锚点。颜色不必完全服从真实物体，可根据画面节奏进行局部换色、错色和跳色，但必须保持整体和谐。色块应平涂、干净、克制，避免脏灰、统一滤镜感和高饱和数字色。

文字不预设固定标题、地点、编号或语种，根据原图的主题、动作、环境、情绪或隐喻自由生成极少量真正有意义的文字。文字可作为版式系统的一部分，置于留白区、底部中心、边角或几何分区之间，使用细瘦、克制、疏朗的排版方式，与几何结构形成呼应；整体保持小、轻、安静，不机械套模板。

整体气质应像**建筑图解、艺术地图、现代拼贴海报与高级编辑设计**之间的结合：安静、理性、精致、现代，同时保留记忆化提炼与色彩温度。避免完整场景复刻、随机像素化、贴纸逻辑、繁复纹理、光滑3D、卡通模板感和为了丰富而加入无意义元素。
