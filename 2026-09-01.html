余温：REALITY 指向 Cloudflare 会被当匿名出口

余温 @gkxspace

DMIT 以「窃取 OpenAI 和 Cloudflare 的资源」停机。原因：公网 443 + REALITY 的 target/SNI 指向 Cloudflare，未认证请求回落到第三方，别人不用 UUID 也能借这台 VPS 当匿名出口。又花 $49.9 买搬瓦工重搭；DMIT 后来解封。

整改：停掉旧 x-ui/Xray 取消开机启动；REALITY target 改 127.0.0.1:8443，SNI 换成自己的域名，Cloudflare 只做 DNS；管理面板只监听本机。跟帖补一句：风险就是 target 和 SNI 指向 Cloudflare。

向量库不是普通库加一列：整栈只为近邻检索

Alex Prompter @alex_prompter

转 @claudeskills101 长帖。向量库不是普通数据库加一列。嵌入把文本变成稠密向量，相似度用距离不是精确匹配。元数据跟着每条向量，用来过滤，不替代向量。

要快靠索引：HNSW / IVF / PQ 做近似近邻，而不是和库里每条比一遍。索引、向量、元数据住在同一个库，检索是一次查询不是跨系统 join。返回 top K 带分数，再按 source/date 过滤。

这就是 RAG：切块 → 嵌入 → 只把 top K 交给 LLM。Pinecone / Weaviate / Milvus / Qdrant / Chroma / pgvector 做同一件事、取舍不同。
