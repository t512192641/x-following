M. @wlzh

GitHub - JustAResearcher/gpu-unlock-ada: GPU tensor unlock source for RTX 4090 and experimental RTX...

有个开源项目 gpu-unlock-ada，干的是给 RTX 4090 解锁张量算力，办法是做个 Linux 内核模块，在官方 NVIDIA 驱动启动之前先把速度选择覆盖打开。

作者给的数据挺夸张，RTX 4090 上 FP16 和 BF16 张量吞吐在 FP32 累加下都接近翻倍，从 165.6 TF/s 左右涨到 331.6 TF/s 左右。

不过要分清，上面是张量指令吞吐，实际 cuBLAS GEMM 的中位数提升没那么大，FP16 涨了 12% 到 34%，BF16 在两个形状上是 16% 到 20%，4096 立方那个形状基本没变。

另外一个独立机主在 Arch 上复跑了一遍，结果也差不多，FP16 从 160.4 涨到 320.4 TF/s，BF16 从 159.7 涨到 320.2 TF/s，数值检查都通过了。

这个项目不光是 4090，还把 Ada 的口子做了实验性移植，RTX 4070 Ti SUPER 上冷启动测出来 FP16 和 BF16 也接近翻倍，从 95 TF/s 涨到 189.9 TF/s 左右，TF32 则是 47.49 涨到 94.51 TF/s。

但 FP8 就没这么好看，同一个 E4M3 的 CUTLASS GEMM 只从 59.326 涨到 59.495 TF/s，0.3% 的差别，基本等于没涨。

4070 Ti SUPER 和 4060 Ti 16GB 都只是实验目标，各自只在一张卡上验证过，其他板子没验证过，项目自己也说共享固件不等于支持没测过的卡。

Windows 那边还有个实验性的 MSI 4070 Ti 参考移植，单次手动启动测出 FP16 涨 80.1%，但只绑一张卡的配置，不算进 Linux 模块的支持范围。

仓库是 GPL-2.0 开源，固件是在本地生成的，不直接发预编译的固件包，刚建两天就已经破千 star 了。

这种改动毕竟动的是固件和驱动启动顺序，作者也提醒要留一个没改过的启动项，出了问题能回去。https://github.com/JustAResearcher/gpu-unlock-ada

Impeccable 是给 AI 编程助手用的设计指导，核心就一个 skill、24 条命令，再加 62 条确定性检测规则，目标是让 AI 做出来的前端别再一眼 AI 味。

它最早是从 Anthropic 的前端设计 skill 演化来的，作者说的问题很实在，所有模型都学同一批 SaaS 模板，不给指导，做出来全是一个样。

用法先跑一次 init，它会把产品的受众、用途、使用场景、约束、语气这些硬事实写进 PRODUCT.md，后面命令就按这个来，不会把产品事实和视觉风格混在一起，视觉系统另外记在 DESIGN.md 里。

文明 4 Beyond the Sword 开源 LLM mod：每个文明开一个 Claude Code（也可 Codex/pi）会话自己打整局；笔记/邮箱文件夹 JSON/一条 civ 命令外置记忆，解决「每次从零」

yibie @yibie

一个开源 mod 把《文明 4：超越刀锋》里的电脑对手换成了 LLM。每个文明开一个 Claude Code 会话，也可以挂 Codex 或经 pi 接别的模型，这个文明整局由它自己打。它要解决的是同类问题里最烦的那个：模型每次被调用都从零开始，记不住上一轮自己想干什么。

作者的答案是把三样东西放到模型外面。

1. 笔记。每个文明在游戏目录里存一份自己的笔记：人设与计划，对其他文明的档案，还有藏着的秘密。每次叫醒它，笔记重新塞回提示里。记忆是一个文件，跟对话历史无关。

2. 邮箱。mod 和模型不直接通信，靠一个文件夹传 JSON，请求进、答案出。

3. 一条命令。civ。看自己的帝国和地图、调兵都走它；发消息、开交易、结束回合也走它。人类能做的动作都在这条命令里。

叫醒的时机是事件：新回合、收到消息、收到交易。每次给的都是全新提示，只装三样东西——PLAYBOOK.md 里的规则、它自己的笔记、上次之后发生了什么。它落子，改笔记，睡回去。

信息隔离做得很实。mod 只收集这个文明看得见的东西，雾战和人类玩家一样。游戏引擎被打过补丁，把这个文明的内置 AI 关掉，落子才全是模型的。

对话这一层也能拿来玩：公开和私聊、交易、投票都走同一条通道，每条消息还附一条模型本意的私有注记，复盘时能看出它嘴上说的和实际想做的差多远。

我的判断：值得抄的跟「让 AI 打游戏」没什么关系。值得抄的是把 agent 的长期状态放到模型外面，文件夹当接口，笔记当记忆，每次只喂规则和差异。跨多次调用的 agent 卡在记不住上，先照这三件事改。

门槛写在 repo 里。不装引擎补丁 mod 也能跑，但内置 AI 会继续替模型做一部分选择，补丁得自己用 BtS 3.19 的 SDK 和 MSVC 7.1 编译。作者在 Mac 加 CrossOver 上开发测试，Windows 要改 https://install.sh/ 里的路径。另外需要 Python 3.10 以上和至少一个 agent CLI，用订阅就能跑，不用 API key。

一局跑了多少次唤醒、花了多少钱，作者一个数没给。repo 里有 https://metrics.py/，按 API 价格把唤醒次数、思考时间、消息与交易数算出来，值不值得跑得自己先跑一局。

辅导孩子学习诗词 Prompt： --------------------- 你要把一首诗变成一幅只由诗中文字组成的图。字的位置和走向就是画面…

李继刚 @lijigang

辅导孩子学习诗词 Prompt： ---------------------

你要把一首诗变成一幅只由诗中文字组成的图。字的位置和走向就是画面本身：读者既能看出画面，也能顺着一条路径把整首诗读下来。

第一步，找事实。读诗，写出画面里有哪些东西，以及它们之间的关系：谁在上，谁垂下，谁在动，往哪个方向动。只写诗里有的，不添加。

第二步，定投影。

- 每个东西由诗里指称它、或者描写它的那些字构成。 - 关系换成空间关系：垂下就让字沿弧线往下排，高就让字竖着往上叠，风就让字斜着横穿画面。 - 表示疑问、否定、比喻的字（如"不知""谁""似"）不对应任何东西，放在空白处或两个意象的交界处，用位置显示它们的作用。

第三步，排出来。输出一张图片，元素是文字，呈现这个意向

第四步，对照检查。逐条核对，有一条不满足就改，直到全部满足：

1. 图中所有字都出自原诗。为了让画面饱满，可以重复使用诗里的字。 2. 不看原诗的人能认出这是什么画面。 3. 按阅读路径能把原诗一字不差读下来。 4. 每个意象都由指称它的字构成，不拿别的字凑。

诗：{在这里放诗}

Mai Yang @MaiYangAI

Andy Jassy 谈 AI 基建：花 2200 亿，需求没接上

Amazon CEO Andy Jassy 上了 a16z 的播客，对面是 a16z 联合创始人 Ben Horowitz，以及 Erik Torenberg。话题是 AI 时代需要怎样的基建。开场他就说，即使今年花 2200 亿美元，仍留下可观的需求没有接上。2026 年产能已售罄，2027 年大多卖完，2028 年也卖掉一大块。

他 2021 年正式接任 CEO，到现在满五年。上任时正好赶上疫情尾声，零售履约网在大约 18 个月里几乎翻倍，又用大约 20 个月建起规模赶上 UPS 的最后一公里运输网。建得太快留下一堆没优化的服务成本，那几年主要在修这些。生成式 AI 起来以后，增速完全不是一回事。他说 AWS 业务上个季度同比增长 36.7%，年化营收约 1690 亿美元；单看 AWS 里的 AI，生成式 AI 浪潮最初三年已超 250 亿美元年化，而 AWS 早期三年后才大约 6000 万美元年化，快了几百倍。他觉得这业务长期能到几千亿美元收入。

CapEx 怎么定？他说数据中心要提前几年投，服务器和网络设备按组件提前几个月就够。扣扳机前，他们对客户需求已经很清楚。今年大约花 2200 亿，其实还能花更多，中长期也划算，但可能仍然无法满足所有需求。他把当下 AI 需求看成杠铃。一端是狂吞算力的 AI 实验室和少数爆款应用，另一端是企业用来省成本和提效率的场景，中间才是将来最大的一块，也就是企业生产应用普遍用上推理。

芯片这条线从 2015 年买下 Annapurna Labs 讲起。当初并不是为了 AI 芯片本身，先是把虚拟化、网络、安全、存储卸到网卡上，好把服务器产能留给客户计算；后来做出 Graviton，前 1000 名 EC2 客户里 99% 在用，性价比大约比其他 x86 高 40%。AI 起来以后，又在 Annapurna 分出一支团队做加速器 Trainium，性价比约高 30% 到 40%。投资上，主持人提到他们对 Anthropic 大约 180 亿、对 OpenAI 大约 500 亿量级的投入。Andy 说两家团队都很强，客户想在 Bedrock 上跑这些模型；Anthropic 在 Trainium 上已开发一段时间，也对 Trainium 做了多年、多吉瓦的承诺。

组织上他看得很直接。Bedrock 团队曾用六名工程师、76 天重建推理引擎，按过去节奏大概要 40 人一年。他觉得将来团队会比现在小得多，很多场景里模型能帮人走到大约八成，公司将不得不重写几乎所有代码，好让 agent 能改不同片段。安全上更急。模型会找出人没找到的漏洞，补丁必须在几分钟内部署。产品上，他拿 Alexa 举例，生成式 AI 让「大脑」能做的事完全不同，必须重接；零售、Prime Video、Fire TV、Prime Music 这些现有体验，也得从零重想，只做渐进改进很难赢。谈到年轻人怎么用 AI，他说工具会是巨大的助手，但他认为 AI 取代不了批判性推理，仍然需要人的判断。
